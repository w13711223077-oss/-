# 14. 权限与数据可见性 — 数学审题逐题陪练

> 上游：11、12、13。下游：15、18、24。
> 本文回答：**谁能看什么、同一份数据对谁投影成什么**。
> 样板 ChemAI 的 22 号文是「角色 × 资源」矩阵；我们只有学生一个角色，所以重点不是“谁能不能进”，而是**同一份内部记录对学生的可见粒度**。

---

## 一、角色

| 角色 | v1 | 说明 |
|---|---|---|
| **学生** | ✅ 唯一使用者 | 匿名、无登录、无姓名/学校/班级/手机号 |
| **家长** | ❌ 无界面 | v2 只读一条周摘要（约 30 秒） |
| **教师** | ❌ 无界面 | v2 只读匿名班级摘要，不打开产品 |
| **管理员 / 运营** | ❌ v1 不存在 | 未来做数据删除/审计时再引入 |

> 06·二：教师产品内行为 0 次；家长一周只有 1 个触点、约 30 秒。v1 不做任何对外界面（11·§6·决策 6）。

---

## 二、角色 × 资源矩阵

| 资源 | 学生 | 家长（v2） | 教师（v2） | 内部审计 |
|---|---|---|---|---|
| 本次会话的题目文本 | ✅ 自己 | ❌ | ❌ | ✅ |
| 审题分句 / 条件级别 | ✅ 自己 | ❌ | ❌ | ✅ |
| 每句的判定结果（一致/不一致/不判定） | ✅ 自己 | ❌ | ❌ | ✅ |
| 判定依据（哪句、哪一级） | ❌ **不可见** | ❌ | ❌ | ✅ |
| 卡点证据（具体句子 / 条件） | ❌ **不可见** | ❌ | ❌ | ✅ |
| 卡点类型 + 数量级 | ✅ 自己 | ✅ 聚合 | ✅ 匿名聚合 | ✅ |
| 错题 / 待再看的题 | ✅ 自己 | ❌ | ❌ | ✅ |
| 完整答案 / 解法 / 参考解 | **系统中不存在** | ❌ | ❌ | ❌ |
| 姓名 / 学校 / 班级 / 手机号 | **不采集** | — | — | — |

## 三、可见性投影（本项目的核心权限设计）

样板 ChemAI 的权限是“角色能不能访问”；我们的权限多一层：**同一份记录，内部与学生的投影不同**。

### 3.1 三层数据

| 层 | 例子 | 谁能看 |
|---|---|---|
| **内部证据层** | 「第 3 句『最后一辆车只坐 15 人』没用上」 | 只有服务端 / 审计 |
| **聚合层** | 「有 3 个条件没用上」 | 学生本人 |
| **对外摘要层** | 「今天练了 1 道题，隐含条件找得比上周稳」 | 家长（v2，无排名） |

### 3.2 投影规则

```
内部 CheckpointEvent
  ├─ 学生投影：{ type, count, severity }        ← 只给数量级
  ├─ 家长投影：{ 时间维度的一句话 }             ← v2，无细节
  └─ 审计投影：{ evidence_ref, verdict, model }  ← 只在内部
```

- **学生端永远不返回 `evidence_ref`**（具体句子 / 条件 / 级别）。
- **家长端永远不返回逐题明细**，只返回“这类题最近两周能不能自己找出来”这类时间维度判断。
- **教师端只返回匿名聚合**，不返回学生姓名。

### 3.3 数据字段级约束

| 字段 | 约束 |
|---|---|
| `answer` / `solution` / `final_value` / `reference_step` | **不进入任何面向学生的响应**；模型输出若带这些字段，`audit.py` 在返回前剥离 |
| `evidence_ref` | 只存内部；API 序列化时白名单过滤 |
| `student_name` / `school` / `class` / `phone` | 不采集；数据模型里没有这些字段 |
| 原始图片 | 只在会话内使用；v1 不落盘原图，只落确认后的文本（18） |
| `confidence` | 内部字段；学生端只映射成「不判定 / 已确认」这种教学动作 |

## 四、会话级隔离

| 规则 | 说明 |
|---|---|
| 一会话一 ID | `session_id` 随机生成；不暴露学生身份 |
| 会话只能被创建它的客户端读写 | v1 无账号，用随机 ID + 本地存储；不提供列表接口 |
| 跨会话不合并 | 每次打开是新会话；重练走「未清账目」入口（v2） |
| 丢弃即终止 | `DISCARDED` 后不可再答；不写卡点库 |

> 样例 ChemAI 用“学校→年级→班级”做多租户隔离；我们没有组织层级，隔离单位就是**会话**。

---

## 五、未成年人数据

| 约束 | 做法 |
|---|---|
| 不采集身份信息 | 姓名 / 学校 / 班级 / 手机号均不采集（01·L1、02·S7） |
| 数据最小化 | 只保留审题所需的题目文本、分句、判定、卡点 |
| 不用原始照片长期留存 | v1 只落确认后的文本；原图在请求结束后丢弃 |
| 若未来加账号 | 监护人同意必须在流程内可证明，不能只写在隐私政策里（01·L1） |
| 删除权 | 未来提供“删除这次记录 / 删除全部记录”的入口（24） |
| 不做排名 / 跨人比较 | 不出现分数、排行榜、班级对比（02·S7、11·§7） |

## 六、v2 扩展时的权限边界

| 未来功能 | 允许 | 禁止 |
|---|---|---|
| 家长周摘要 | 时间维度、类型级、可操作建议 | 逐题明细、排名、孩子身份、其他孩子 |
| 教师班级摘要 | 匿名聚合、共性问题 | 学生姓名、单个学生详情 |
| 账号体系 | 监护人同意、删除权 | 用手机号/姓名做默认身份 |
| 数据导出 | 学生/家长可导出自己的记录 | 导出他人/全班数据 |
