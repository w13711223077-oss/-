# 20. 前端页面规格 — 数学审题逐题陪练

> 上游：13、19。下游：21、23。
> 样板 38 号文把 14 页集中成规格；我们只有 1 页 8 状态，所以本文按 **状态** 写规格。
> 原则：单页 HTML、原生 JS、零构建；页面只是服务端会话状态的渲染器。

---

## 一、视觉与布局

| 项 | 规格 |
|---|---|
| 画布 | 单页，移动优先；最大宽度 720px 居中 |
| 背景 | 暖纸色 `#f6f2e9` + 极淡的双色径向渐变 |
| 卡片 | `#fffdf8`、1px 边、20px 圆角、轻阴影 |
| 标题 | 宋体/衬线（Songti SC / Noto Serif CJK），24—32px |
| 正文 | 系统中文 sans，15—16px，行高 1.8 |
| 主色 | 深青 `#2f6b5f`；点缀暖金 `#b27a2c` |
| 按钮 | 12px 圆角；主按钮深青底白字；次按钮白底描边；ghost 无底 |
| 选项 | 2 列（S5）/ 3 列（S6）；每项含主词 + 一句解释 |
| 无 | 无首页、无菜单、无 tab、无进度条、无积分、无排名、无答案入口 |

---

## 二、全局元素

| 元素 | 规格 |
|---|---|
| 顶栏 | 左「审题陪练」品牌；右「语音：开/关」 |
| 步骤条 | 一行小字：`S5 · 逐句标注`；不显示百分比 |
| 卡片 | 所有内容在卡片内；一次只显示一个状态 |
| 家长说明 | 页脚一行小字：「给家长：它不给答案，只教孩子把题读懂。」 |
| 加载层 | 全屏半透明 + 旋转指示 + 一句「我在看题…」 |
| Toast | 底部胶囊，2.8 秒消失；只用于轻提示 |
| 错误屏 | 标题 + 原因 + 「再试一次」+「回到开头」 |

---

## 三、S1 拍照 / 粘贴

```
标题：先把这道题读一遍
副标题：不着急做。它觉得你能想出来。
[ 拍照 / 选图 ]  [ 直接粘贴题目 ]
（选中图片后显示预览 + [用这张图]）
（粘贴框 + [用这段文字]）
提示：拍作业本上的应用题；识别不准也没关系，下一步可以改。
```

| 项 | 规格 |
|---|---|
| 主操作 | 拍照/选图（`capture="environment"`） |
| 次操作 | 粘贴文本（F13 兜底） |
| 空状态 | 两个按钮即可，不要表单 |
| 错误 | 「这张看不清，换一张，或者把题目粘进来」 |
| 禁止 | 不做「拍照秒出答案」的暗示；不出现答案/解析入口 |

---

## 四、S2 确认题目

```
标题：题目读对了吗？
副标题：有认错的字，直接改。题目错了，后面全错。
[ 多行文本框：识别结果 ]
[ 对，继续 ]  [ 重新拍 ]
```

| 项 | 规格 |
|---|---|
| 文本框 | 预填识别结果，可编辑；高度 6 行 |
| 校验 | 空文本不允许继续 |
| 错误 | 「题目不能是空的」 |
| 关键 | 这一步既是防错闸门，也是审题第一环；**不能做成后台自动确认** |

---

## 五、S3 备课（不可见）

- 不是独立屏；显示加载层：「我在把这道题拆开…」+ 「不判对错，只把句子和条件理清楚。」
- 成功 → S4；失败 → 错误屏，可重试；无 key → 提示设 key 或开桩模式。
- 前端**不展示**备课中间结果（学生不可见）。

---

## 六、S4 开场

```
标题：准备好了吗？
大字：我们先把这道题读一遍，不着急做。
小字：这一遍不写算式，只把题读懂。
[ 开始读题 ]
```

- 进入时 TTS 朗读大字（若语音开）。
- 不出现解法、不出现题目正文的朗读（读题是学生的事）。

---

## 七、S5 逐句标注

```
标题：一句一句看
小字：第 2 / 5 句。先看它在这道题里干什么。
[ 句子原话 ]
[背景] [条件] [问题] [指令]
 交代情境  给了数字  在问什么  要求你做什么
（作答后反馈区 + [继续]）
```

| 项 | 规格 |
|---|---|
| 句子 | 大字衬线，最多 3 行；不显示类型提示 |
| 选项 | 4 个；主词 + 一句解释；一次只能点一个 |
| 反馈 | 一致：「对了。」+ 依据；不一致：线索式提问；不判定：「你为什么这么想？」 |
| 降梯 | 15 秒 → 一句线索；40 秒 → 记卡住，显示「这一步先记下来，我们继续」 |
| 推进 | 反馈后的「继续」推进下一句；不是自动跳 |
| 禁止 | 不显示「你错了」「你又漏了」；不一次展示全部句子 |

---

## 八、S6 条件定级

```
标题：给条件分个级
小字：第 1 / 2 条条件。它能直接拿来用吗？
[ 条件句原话 ]
[直接] [间接] [隐含]
 拿来就能用  要转一步  题目没说但必须成立
```

- 只对 `prep` 里 `type=条件` 的句子提问。
- 灰度（备课 confidence 低）：只提问，不判级。
- 反馈/降梯同 S5，线索改为「它是拿来就能用，还是要先转一步？」。

---

## 九、S7 隐含条件

```
标题：有没有藏起来的那句话？
小字：这几句里，有没有藏着一个没说出来的东西？用一句话说说看。
[ 文本域 ]
[ 说说看 ]  [ 我说不出来 ]（15 秒后出现）
```

| 项 | 规格 |
|---|---|
| 输入 | 一句话即可；打字慢是已知摩擦（06·P1） |
| 「说不出来」 | 延迟 15 秒出现；点击后标记，不显示失败 |
| 追问 | 未命中只追问一次；「你说的这个，能再说说为什么吗？」 |
| 结束 | 说出/说不出/追问后 → S8 |
| 禁止 | 不直接告诉学生隐含条件是什么；不无限追问 |

---

## 十、S8 收束

```
标题：这道题你已经读明白了。
大字：你一句一句看了 5 句，亲手标了 5 句，给 2 条条件定了级。
小字：现在你可以去写了——写完拍给我看。
提示：首体验到这里结束。写解答、批改和变式题是下一次的事。
（判定未上线时）这次我只提问、没有判对错；没有写入卡点库。
[ 重新开始 ]（ghost，小号）
```

- 不是评分；说具体动作，不说“你真棒”。
- 没有「再来一题」大按钮；没有排行榜/积分。
- 不写库（Gate 0 前）或不显示细节。

---

## 十一、状态与异常

| 状态 | 表现 |
|---|---|
| 空 | 只有下一步动作，不显示空表格/空列表 |
| 加载 | 全屏加载层 + 一句具体的话（不写“加载中…”） |
| 错误 | 错误屏 + 原因 + 重试 + 回开头 |
| 无 key | 「服务端没有模型 key。先开桩模式，或设 DEEPSEEK_API_KEY」 |
| 断网 | Toast「没接上，先不判」；不吞掉 |
| 40 秒 | 记卡住，继续；不弹惩罚性提示 |

---

## 十二、语音与可访问性

| 项 | 规格 |
|---|---|
| TTS | Web Speech API，`zh-CN`，rate 0.95；只读教练话术，不读题目正文 |
| 开关 | 顶栏「语音：开/关」；关闭即 cancel |
| 无障碍 | 按钮可键盘操作；反馈区 `aria-live="polite"`；颜色对比 ≥4.5:1 |
| 动效 | 尊重 `prefers-reduced-motion` |
| 移动 | 单列；选项至少 44px 高；文本域不自动聚焦（避免弹键盘） |

---

## 十三、禁止清单

- 答案/解析/解法入口
- 分数、排名、跨人比较、贴标签
- 积分、连续打卡、排行榜、内容流
- 「再来一题」无限流
- 姓名/学校/班级/手机号字段
- 「提分」「AI 精准诊断」「大模型/多模态」等话术
- 把开放环节做成点选
