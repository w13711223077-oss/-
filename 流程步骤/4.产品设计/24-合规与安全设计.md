# 24. 合规与安全设计 — 数学审题逐题陪练

> 上游：11、14、20。下游：无（上线前必读）。
> 样板 25 号文是「四维安全审核引擎」；我们的安全不审化学方程式，审 **「答案泄露 / 未成年人 / 数据最小化 / 品类定性」**。
> 一句话：**「不给答案」不是文案，是合规身份；不能成为第一个被商业压力牺牲的东西。**

---

## 一、四条不可越过的线

| # | 线 | 为什么 | 怎么守 |
|---|---|---|---|
| 1 | **产品里不存在「答案」入口** | 拍照搜题的监管阴影；这是合规身份（01·P1、02·S2） | 形态上无入口；模型提示词禁答；数据模型无 answer 字段；审核剥离 |
| 2 | **批改只给数量级，不点名** | 点名 = 换一种方式给答案（11·决策 8） | 学生投影只给 type/count；evidence 内部 |
| 3 | **误判正例率 = 0 才上线** | 学生会照错误标准改自己（05·8.3） | Gate 0；judge 默认不判定 |
| 4 | **不采集身份信息** | 12—13 岁，PIPL 31 条（01·L1） | 无姓名/学校/班级/手机号；会话即隔离 |

## 二、未成年人数据

| 项 | v1 做法 | 上线前 |
|---|---|---|
| 身份信息 | 不采集 | 保持 |
| 题目文本 | 只落确认后的文本；原图不落盘 | 明确保留期与删除 |
| 审题记录 | 落卡点/练习记录；无身份 | 提供删除入口 |
| 账号 | 无 | 若加，监护人同意必须在流程内可证明 |
| 数据出境 | 模型 API 调用；需确认供应商与数据条款 | 做正式评估 |
| 儿童个人信息处理规则 | 未建 | 必须建（01·L1） |
| 不良信息输出审查 | 提示词铁律 + 审核 | 上线前补记录与抽检 |

## 三、内容安全

### 3.1 答案泄露

| 层 | 做法 |
|---|---|
| 提示词 | 铁律：不给答案/不给解法/不写解题过程；批改只给数量级 |
| 数据 | `answer/solution/final_value/reference_step` 不进入学生响应；模型输出剥离 |
| 前端 | 无答案入口；无「查看解析」 |
| 测试 | L3 答案泄露扫描：响应/页面/日志不出现答案字段 |
| 人工 | 发布前抽检 20 条话术 |

### 3.2 AI 生成内容标识

| 场景 | 标识 |
|---|---|
| 对话/教练话术 | 界面标注「本对话由 AI 生成」 |
| 变式题（v2） | 「本题由 AI 基于你的原题改编」 |
| 家长摘要（v2） | 「由 AI 生成，仅供参考」 |

### 3.3 品类澄清

- 第一屏/第一句话必须让家长在 3 秒内判断「这不是搜题工具」。
- 对教师：「这不是搜题工具——学生审完题要自己写解答，它只点评。」
- 对外材料：禁用「搜题/拍题/秒懂/一拍即得/答案解析」；统一「审题/陪练/读懂题意」。

## 四、合规清单（上线前）

- [ ] 产品内无答案/解析入口（形态检查）
- [ ] 提示词铁律 + 答案字段剥离 + 泄露扫描通过
- [ ] 不采集姓名/学校/班级/手机号
- [ ] 原始图片不长期留存；文本保留期明确
- [ ] 删除入口（单次/全部）
- [ ] 若加账号：监护人同意流程 + 儿童个人信息规则
- [ ] AI 生成内容标识
- [ ] 与搜题类的差异说明一页纸（备案/上架材料前置）
- [ ] 教育移动应用备案/算法备案评估（公开分发前 1—3 个月启动）
- [ ] 数据出境/供应商条款确认
- [ ] 内容审核记录与抽检机制

## 五、风险登记

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 被误认为拍照搜题 | 高 | 极高 | 形态区隔 + 第一屏澄清 + 差异说明 |
| 模型误判正确为错误 | 中 | 极高 | Gate 0；不判定；误判正例=0 |
| 答案从提示词/模型输出泄露 | 中 | 极高 | 铁律 + 字段剥离 + 扫描 |
| 学生数据被跨会话读取 | 中 | 高 | 随机 session_id；上线前鉴权 |
| 家长要求“给答案” | 高 | 中 | 定位 4+1；不承诺提分；主动劝退 |
| 监管收紧变式题生成 | 中 | 中 | 退路：基于原题改动 / 去掉生成 |
| 首体验超 20 分钟 | 中 | 高 | Gate 1；砍环节不优化措辞 |
| 批改不可靠 | 中 | 极高 | Gate 2；S10 不上线 |
