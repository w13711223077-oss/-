# CONTEXT.md — 领域术语表

> 目的：**同一件事只用同一个词**。写代码、写文档、和 AI 对话时，用这里的名称。
> 每条一句话定义；出处指向 `流程步骤/4.产品设计/` 的编号文档。

---

## 一、核心实体（Core Entities）

| 中文 | English | 一句话定义 | 出处 |
|---|---|---|---|
| 会话 | Session | 一次 S1—S8 首体验的完整状态，含题目、备课、作答、卡点、收束 | 15、18 |
| 题目 | Problem | 学生拍照或粘贴的那一道题；`confirmed_text` 是后续唯一真源 | 15、18 |
| 确认文本 | Confirmed Text | S2 学生核对/修改后的题目文本；之后不再改动 | 15、18 |
| 备课解剖 | Prep | F2 对题目的结构化解剖：分句、类型、级别、隐含条件集合、不确定项 | 15、18 |
| 分句 | Sentence | 备课把题目切开的一句；带 `i / text / type / level / confidence / note` | 15、18 |
| 作答 | Answer | 学生对某一句/某条条件/隐含问题的单次回答与判定结果 | 15、18 |
| 卡点事件 | Checkpoint Event | 一次「卡在哪一步、什么类型、结果如何」的结构化记录 | 16、18 |
| 变式题 | Variant | 以学生原题为蓝本、把条件改深一级的题；首体验不触发 | 16、18 |
| 错题项 | Wrong Item | 做错的原题/变式题，用于之后重做；学生侧叫「待再看的题」 | 16、18 |
| 练习记录 | Exercise Record | S12 落库的一次练习：题目、时长、是否一次通过、卡点、错题 | 16、18 |
| 事件日志 | Event Log | 会话状态转移、备课锁定、作答、收束的审计事件 | 17、18 |

## 二、学习概念（Learning）

| 中文 | English | 一句话定义 | 出处 |
|---|---|---|---|
| 审题 | Problem Reading | 在动笔之前把题目读懂：分句、找条件、分级、说出隐含条件 | 11 |
| 句子类型 | Sentence Type | 背景 / 条件 / 问题 / 指令四类；S5 的判定对象 | 11、18 |
| 条件级别 | Condition Level | 直接 / 间接 / 隐含三级；S6 的判定对象 | 11、18 |
| 隐含条件 | Implicit Condition | 题目字面没写、但解题必须成立的条件；是**集合**不是单点 | 11、15 |
| 降梯 | Ladder / Hint Ladder | 学生卡住时只给一次线索；40 秒上限从时间上强制「只降一次」 | 11、15 |
| 首体验 | First Experience | S1—S8 的审题弧线；目标 ≤15 分钟、红线 20 分钟 | 11、15 |
| 思考下限 | Think Floor | 学生没动静时，系统至少等 15 秒再开口 | 11、15 |
| 单步上限 | Step Ceiling | 一步 40 秒还没过，记「卡住」继续；不是学生慢，是这一步设计不对 | 11、15 |
| 数量级定位 | Quantity-Level Feedback | 批改只说「有几个/哪一类」，不点名具体条件；把「找」留给学生 | 11、14 |

## 三、诊断概念（Diagnosis）

| 中文 | English | 一句话定义 | 出处 |
|---|---|---|---|
| 卡点 | Checkpoint | 学生在某个审题环节没通过的结构化记录 | 16 |
| 标注错 | Labeling Error | S5 句子类型贴错 | 16 |
| 定级错 | Leveling Error | S6 条件三级判错 | 16 |
| 隐含条件未说出 | Implicit Miss | S7 追问一次后仍说不出 | 16 |
| 变式题未通过 | Variant Fail | S11 变式作答未通过（只在触发时） | 16 |
| 推一把过了 | Passed After Push | 隐含条件第一次没说出，追问后说出 | 16 |
| 推一把也没过 | Failed After Push | 追问后仍说不出 | 16 |
| 暴露数 | Exposure | 走到该步骤的次数；画像的分母，不用「总失败数」 | 16、18 |
| 未判定 | Undetermined | 备课标了低置信 / P0 未通过 / 无法确认；不写 pass/fail | 15、16 |
| 首因节点 | First Failed Node | 一次会话里最先失败的步骤；主归因用它，不替代多标签 | 16 |
| 可见性投影 | Visibility Projection | 同一份内部记录对学生的输出：只给类型/数量，不给证据 | 14、18 |
| 待再看的题 | To-Revisit Problems | 学生侧对「错题库」的叫法；不叫错题库、不叫未清账目 | 11、16 |

## 四、题目、练习与重练（Problems & Practice）

| 中文 | English | 一句话定义 | 出处 |
|---|---|---|---|
| 源题 / 原题 | Source Problem | 学生自己拍的那道题；变式的唯一蓝本 | 16 |
| 变式题 | Variant | 同情境、同结构、条件加深一级的题；是验收不是加练 | 16 |
| 错题库 | Wrong-Problem Bank | 做错的原题 + 变式题；学生的诊断资产，只对有账的学生成立 | 11、16 |
| 卡点记录库 | Checkpoint Bank | 四类卡点事件的长期记录；是画像，不是待办 | 11、16 |
| 未清账目 | Open Items | 还没重做的错题；`有账` 只看错题，不看卡点 | 16、18 |
| 重练 | Re-practice | 重做某道错题，或针对某类卡点再练几道 | 11、16 |
| 审核状态 | Audit Status | 变式题的 `passed / warning / blocked`；blocked 打回重生成 | 16 |
| 题目来源 | Problem Source | 图片 / 文本；v1 只有学生带来的题，没有题库 | 15、18 |

## 五、Agent、工具与流程（Agent Concepts）

| 中文 | English | 一句话定义 | 出处 |
|---|---|---|---|
| 角色 | Persona | 一组工具白名单 + prompt + 数据访问；v1 只有「审题教练/学生」 | 17 |
| 工具 | Tool | 一个动词动作：read_problem / prep_problem / judge_answer / probe_implicit / close_session / save_record | 17 |
| 工具元数据 | TOOL_META | 工具 → 允许状态 + 调用上限的声明表 | 17 |
| 顺序门 | Guard L1 | 工具只能在允许的会话状态调用；由 `flow.py` 强制 | 17 |
| 限次 | Guard L2 | 同一工具/同一目标的调用次数上限 | 17 |
| 去重 | Guard L3 | 同一工具 + 同一参数的重复调用拦截 | 17 |
| 确定性编排 | Deterministic Orchestration | 下一步由状态机决定，不由 LLM 自由选；LLM 只在工具内部判断 | 17 |
| 状态机 | State Machine | 12 个会话状态 + 转移表 + 守卫；会话状态是唯一真相 | 15、18 |
| 桩模式 | Stub Mode | 不调模型的占位实现，只用于走通管道，不用于质量验证 | 15、21 |
| 证据 | Evidence | 卡点的具体句子/条件/依据；只在内部，学生不可见 | 14、16 |

## 六、输入与模型（Input & Model）

| 中文 | English | 一句话定义 | 出处 |
|---|---|---|---|
| 读图抄题 | Read & Transcribe | 让模型把图片里的题目逐字抄出来；只转录，不解题 | 19、21 |
| 兜底输入 | Fallback Input (F13) | 识别失败时允许直接粘贴文本；不经模型 | 11、19 |
| 模型原生读图 | Native Vision | `deepseek-flash` 直接读照片，不搭独立 OCR 层 | 01、21 |
| 备课锁定 | Prep Lock | 备课成功后 `locked=true`；S5/S6/S7 与批改都只读这一份 | 15 |
| 判定三态 | Three Verdicts | 一致 / 不一致 / 不判定；「不判定」是正确答案，不是错误 | 15、18 |
| 误判正例率 | False-Positive Rate | 把学生做对的判成错的比率；红线 = 0 | 22 |

## 七、不要混用的词

| 不要写 | 要写 | 为什么 |
|---|---|---|
| 错题库（对学生说） | 待再看的题 | 不给 13 岁孩子贴「错」的标签 |
| 未清账目（对学生说） | 待再看的题 | 「账」是内部/产品语言 |
| 答案 / 解析 / 解法 | （不存在） | 产品里没有这个入口 |
| BarrierType / 障碍类型 | 卡点类型 | 样板 ChemAI 的词，不是我们的 |
| Question Type / 题库 | 题目 / 源题 | 我们没有题库 |
| AI 精准诊断 / 提分 | 陪练 / 读懂题意 | 不承诺分数，不冒充诊断 |
| 多智能体 / Agent 自主编排 | 确定性流程 + 工具 | v1 不是自由 Agent |
