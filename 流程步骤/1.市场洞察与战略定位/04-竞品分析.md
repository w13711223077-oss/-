# 竞品分析 — 数学审题逐题陪练系统

> 市场：中国 K12 AI 辅助学习工具（C 端 · 学生 / 家长付费）
> 学段：初中七年级 · 应用题
> 日期：2026 年 9 月

> **阅读前必读**：
>
> 1. **本产品尚未开发**（截至 2026 年 9 月）。因此第三章功能矩阵中，本产品的标记代表
>    **「设计上具备」而非「已经实现」**——这是本产品与本文其他竞品在信息性质上的根本区别，
>    竞品的标记代表其已上线的实际能力。**不要把设计当资产。**
> 2. **数据口径**：标注「估算」的数字未经核实；星级评分、威胁等级、发生概率均为主观判断。
> 3. 本文的竞品从**同类文档的 B 端视角换成了 C 端视角**——原文档主要对手是讯飞、学科网这类
>    服务学校的平台，而本产品的对手全部在**家长与学生的手机里**。

## 一、市场概述

### 市场定义

本产品所处市场为**中国 K12 数学学习工具市场**，细分定位为**面向初中七年级学生的审题能力训练**。更具体地说——帮助学生完成从「读完题目」到「知道该怎么做」之间的那一段。

**这不是一个已有品类。** 现有的学习工具全部围绕另外两件事展开：**把题做出来**（讲题、答疑、搜题）和**多做几道题**（题库、练习、自适应推荐）。「把题读懂」处在两者之间，目前没有产品以此为定位。

### 市场结构与竞争强度

```
┌─────────────────────────────────────────────────────────────┐
│   通用 AI 助手（DeepSeek / 豆包 / Kimi / 通义）              │ ← 免费、已在手机里
│   ┌───────────────────────────────────────────────────────┐ │
│   │  家长自己辅导 + 免费讲题内容（短视频 / 公众号）         │ │ ← 份额最大，但无产品形态
│   │  ┌─────────────────────────────────────────────────┐  │ │
│   │  │  拍照搜题类（小猿搜题 / 作业帮）                  │  │ │ ← 形态最像，风险最大
│   │  │  ┌───────────────────────────────────────────┐  │ │ │
│   │  │  │  学习机 / 题库练习类（讯飞 / 步步高 / 洋葱）│  │ │ │ ← 有渠道与内容
│   │  │  │  ┌─────────────────────────────────────┐  │ │ │ │
│   │  │  │  │  审题能力训练 ← 本产品（目前无竞品）  │  │ │ │ │
│   │  │  │  └─────────────────────────────────────┘  │ │ │ │
│   │  │  └───────────────────────────────────────────┘  │ │ │
│   │  └─────────────────────────────────────────────────┘  │ │
│   └───────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

**本产品处在一个缝隙中。** 但这个缝隙与同类文档中描述的缝隙有一个关键区别：

> **B 端的缝隙是「大平台不愿意做」，而 C 端的缝隙是「需求还没有被确认存在」。**
>
> 前者的风险是「大平台哪天想做」，后者的风险是「**用户根本不知道自己需要**」。
> 后者更难对付——**你无法用更好的产品去赢得一个没有意识到问题的用户。**

### 竞争强度的总体判断

| 竞争维度 | 强度 | 说明 |
|---------|------|------|
| **对「已有需求」的争夺** | 极高 | 讲题、搜题、刷题赛道极度拥挤，本产品不在此列 |
| **对「注意力」的争夺** | 极高 | 学生的课余时间已被占满，家长的钱包也是 |
| **对「付费意愿」的争夺** | 极高 | 免费替代品（通用 AI）随时在同一个手机里 |
| **对「本产品所定位的需求」的争夺** | **极低** | 目前几乎无人以此定位 |
| **对「品类认知」的争夺** | **极低** | 因为品类认知尚不存在——这是最本质的困难 |

**结论：本产品不面对激烈的产品竞争，而面对更艰难的一件事——一个尚未被命名的需求。**

## 二、七大竞争力量（竞品与替代品）

### 竞品 1：通用 AI 助手（DeepSeek / 豆包 / Kimi / 通义）

**概况**：通用对话式 AI 助手。截至 2026 年，国内主流产品的基础功能**完全免费**，且已普遍具备拍照识图能力——**学生拍一道题发过去，就能得到讲解。**

**这是本产品最需要认真对待的对手**，理由不是它做得好，而是**它已经在用户的手机里，而且免费**。

**产品优势**：
- **完全免费**：豆包、Kimi、DeepSeek 的基础对话无使用成本
- **零门槛**：不需要下载新产品、不需要注册新账号、不需要家长同意
- **已在设备上**：用户不需要做任何「安装」这个动作
- **拍照即用**：2026 年的多模态能力使「拍题 → 得到讲解」一步到位
- **综合能力极强**：不限于数学，任何学科任何问题都能回应
- **迭代速度最快**：模型能力以季度为单位提升
- **语音体验成熟**：豆包等产品的语音交互已经做得很好

**产品劣势**：
- **给答案，不给过程**：它的默认行为是解释这道题怎么做，而不是训练学生自己读懂题目——**它的目标是解决这道题，不是解决「读不懂题」这个状态**
- **没有记忆**：每次对话从零开始，无法积累「这个学生常年卡在哪里」
- **说话方式不可控**：不会刻意避免「这道题很简单」「你已经错了两次」这类表达
- **没有结构化诊断**：不会告诉你「这是隐含条件没识别出来」这种分类判断
- **学生容易滑向抄答案**：这是家长最真实的顾虑
- **输出不稳定**：同一个问题在不同时间问，得到的深度与格式可能不同

**定价**：基础功能完全免费；部分产品有会员（**估算** 月费数十元量级）

**竞争威胁**：⭐⭐⭐⭐⭐（极高）

**本产品的应对**：
1. **不与它比方便，比「它做不到什么」**。它更方便、更便宜，这一点无法竞争。本产品要赢的是它结构性做不到的几件事：**不给答案、有记忆、说话方式可控**
2. **做一次公开的对比演示**：同一道题，通用 AI 给出一段讲解；本产品给出一连串问题，并最终让学生自己说出题目在问什么。**这个对比是本产品最有力的说服材料**
3. **强调「没有记忆」这一条**：通用 AI 每次从零开始，而本产品能说出「你这三个月在把间接条件当成直接条件」——**这句话是通用 AI 永远无法给出的**

**关键动态追踪**：
- 通用 AI 是否推出「不给答案的学习模式」？（信号：直接威胁本产品的核心定位）
- 是否推出面向 K12 的「教育版」或家长管控模式？
- 免费策略是否长期维持？（如果开始收费，「免费替代」的压力会缓解）

### 竞品 2：拍照搜题类（小猿搜题 / 作业帮）

**概况**：以「拍照即得答案与解析」为核心的学生端工具。用户基数极大，使用习惯成熟。

**这是本产品在「形态」上最接近的对手**——学生拍照、AI 回应——也因此是**风险最大的对手，但风险不在市场份额，而在品类归类**（详见「01-PESTLE宏观环境分析」P1、「02-SWOT分析」T1）。

**产品优势**：
- **用户基数极大**：学生端渗透率极高，是「拍题」这个动作的默认入口
- **题库规模巨大**：多数题目可直接匹配到原题与解析，响应速度快
- **使用体验成熟**：拍照、裁剪、识别的流程经过多年打磨
- **免费或低价**：基础功能免费，会员价格低
- **学生使用习惯已经形成**：遇到不会的题，第一反应就是拍一下

**产品劣势**：
- **品类已被污名化**：2023—2024 年的媒体曝光之后，「拍照搜题」在老师与家长心中的形象是负面的
- **被教育部门明确限制**：这是它最大的政策风险，也是本产品必须与之划清界限的原因
- **它解决的是「这道题怎么做」，不是「为什么读不懂」**——两者的产品逻辑不同
- **不训练过程**：给出答案的那一刻，思考就停止了

**定价**：基础免费；会员（**估算** 月费数十元量级）

**竞争威胁**：⭐（作为产品竞争）／⭐⭐⭐⭐⭐（作为**品类归类风险**）

**本产品的应对**：
- **必须在第一见面时就划清界限**（见「02-SWOT分析」ST-1）
- 本产品**不给答案**这条设计，是与它最本质的区别，也是合规身份的来源
- **不与它在学生端正面竞争**——它的规模优势无法撼动，但它的品类污名正是本产品需要主动区隔的东西

**关键动态追踪**：
- 这类产品是否推出「不给答案的引导模式」？（如果推出，本产品的差异化会被削弱）
- 监管对拍照搜题的进一步动作（直接影响本产品的定性环境）
- 它们是否开始做「学习过程记录」？

### 竞品 3：学习机厂商（科大讯飞 / 步步高 / 学而思 / 小猿学练机）

**概况**：以硬件为载体、内置 AI 讲题与练习内容的学习平板。客单价数千元，有线下渠道，家长接受度高。

**产品优势**：
- **已完成「为学习工具付费」的市场教育**：这是本产品最大的间接受益者——**家长已经愿意为学习工具花一笔钱**
- **硬件提供信任感**：一台设备摆在书桌上，比一个网页更有「买到了东西」的实感
- **家长管控功能天然存在**：这是学习机相对手机 App 的重要优势，恰好对应本产品面临的 T2（家长对设备的顾虑）
- **内容与题库规模大**
- **语音与多模态能力通常较好**
- **线下渠道与品牌信任**

**产品劣势**：
- **功能重心是「讲题」而非「训练过程」**——它们的设计目标是让学生「会做这道题」
- **不区分「不会做」和「没读懂」**：学习机能讲清楚解法，但不会诊断「你为什么读不懂」
- **客单价高**：数千元一次性投入，且更新周期长
- **内容更新依赖厂商排期**，无法针对单个学生的具体问题即时调整
- **重硬件轻方法**：它们的核心资产是内容和算力，而不是一套关于「怎么学」的方法

**定价**：硬件 **估算** 数千元一次性；内容服务 **估算** 数百至上千元/年

**竞争威胁**：⭐⭐⭐（中）——**当前不直接竞争，但如果它们把「审题训练」做成一个模块，威胁会显著上升**（见「02-SWOT分析」T3）

**本产品的应对**：
1. **借它们已完成的付费教育，直接讲症状**——不需要再解释「为什么要为学习工具花钱」
2. **在它们不愿做的「单题深度」上建立差异**：审题训练需要逐题解剖，这与大厂的规模化内容逻辑不匹配
3. **长期看，它们可能是渠道而非对手**——若「审题训练」被验证有价值，学习机厂商可能需要这样的能力

**关键动态追踪**：
- 学习机是否出现「审题」相关的功能模块？（最直接的威胁信号）
- 它们是否在做「不给答案的学习模式」？
- 学习机厂商的 AI 能力是否从「讲题」转向「诊断」

### 竞品 4：题库练习类 App（洋葱学园 / 猿题库 / 作业帮练习）

**概况**：以题库为核心，提供练习、错题本、知识点讲解。部分产品有较强的动画讲解内容（如洋葱学园）。

**产品优势**：
- **内容资产雄厚**：题量大、覆盖面广
- **错题本功能成熟**：这是与「记录」最接近的功能
- **使用习惯已建立**：学生知道去哪刷题
- **部分产品的讲解质量很高**（动画讲解类的内容制作精良）
- **价格低廉或免费**

**产品劣势**：
- **本质是「多做几道题」的逻辑**：它假设问题是练习量不够，而不是读题方式有问题
- **奖励套公式**：刷题越多，越容易形成「见题套模板」的习惯——**这正是本产品要打断的那个习惯**（对应卡点表第四行「一看像某道题就套」）
- **错题本是「题目的集合」，不是「能力的画像」**：它记录的是「哪道题错了」，不是「哪一类判断反复出错」
- **没有过程性引导**：给的是解析，不是问题

**定价**：基础免费；会员（**估算** 数十元/月或数百元/年）

**竞争威胁**：⭐⭐（中低）——**在付费场景上不直接竞争，但在「注意力」上是直接对手**：学生的时间有限，用在刷题上的时间就不会用在本产品上

**本产品的应对**：
- **定位要说清楚：这不是又一个刷题工具**。前者增加练习量，后者改变读题方式
- 可以主动承认刷题的价值——**审题训练不能替代练习量，它解决的是练习量替代不了的那个问题**

**关键动态追踪**：
- 题库练习类产品是否加入「审题引导」？
- 它们的错题本是否从「题目集合」升级为「能力画像」？

### 竞品 5：家长自己辅导（不是产品，但是最大的竞品）

**当前市场主流**：不是任何 App，而是**家长亲自上阵**。

**「产品」特点**：

| 维度 | 情况 |
|---|---|
| **市场份额** | **估算 > 80%** —— 绝大多数家长的第一反应是自己讲 |
| 成本 | 零现金成本（但消耗时间与亲子关系） |
| 切换成本 | 极低——不需要学任何新东西 |
| 用户满意度 | **低**——家长普遍知道自己讲不好 |
| 能力上限 | 讲不清「为什么这么想」；情绪容易失控；一到初中就讲不动了 |
| 覆盖范围 | 全学科、全时段、随时随地 |

**为什么产品很难赢过「家长自己辅导」：**

1. **零成本诱惑**：「我自己讲不就行了，为什么要花钱」
2. **信任天然存在**：家长不会怀疑自己「判错了」
3. **即时性**：孩子一喊就到，不需要打开任何东西
4. **面子问题**：承认自己讲不了，对一部分家长是困难的
5. **「我小时候就是这么学的」**：路径依赖

**但家长的武器库其实很弱——这是本产品的机会所在：**

| 家长的弱点 | 本产品的对应能力 |
|---|---|
| 讲不清「为什么这么想」 | AI 只提问，不要求家长会讲 |
| 讲两三遍就发火 | 不会发火（这是本产品最容易被家长接受的一句话） |
| 不知道孩子到底卡在哪 | 错题画像能说出具体判断 |
| 离开学校太久，知识点忘了 | 不需要家长懂知识 |
| 没时间 | 学生独立使用 |

**竞争威胁**：⭐⭐⭐⭐（高）——**这是份额最大、也最难转化的「对手」**

**本产品的应对**：
1. **不要与家长竞争「讲题」，要与家长竞争「不发火、讲得清楚」**——把自己定位为家长力所不能及那一段的补位
2. **价值主张用家长的原话**：「讲了八百遍还是错，最后两个人都生气」——这句话比任何产品说明都有效
3. **对家长明确说明「不需要你懂知识」**——这是很多家长没说出口的顾虑

### 竞品 6：免费讲题内容（短视频 / 公众号 / B 站）

**概况**：抖音、B站、小红书上大量数学讲题内容，以及各类教育公众号。**全部免费。**

**产品优势**：
- **完全免费**
- **内容质量参差但优质内容不少**
- **碎片化、易消费**：打开就能看，没有门槛
- **算法推荐**：会主动推到家长面前

**产品劣势**：
- **不是针对学生自己的题**：讲的是别人的题
- **没有互动**：学生看完就结束了，没有人问他「那这道题你觉得在问什么」
- **没有反馈**：做对做错无人知晓
- **无法验证效果**

**竞争威胁**：⭐⭐（中低）——**它不解决本产品要解决的问题，但它占用家长与学生的注意力预算**

**本产品的应对**：
- 免费内容与本产品是**互补而非竞争**：家长可以用免费内容了解「审题是怎么回事」，然后需要产品来实际训练
- **本产品的内容策略应当向「免费讲方法」靠拢**——用免费内容建立品类认知，用产品完成训练

**关键动态追踪**：
- 是否有内容创作者已经在讲「审题」这个话题？（**这是最好的品类认知晴雨表**——如果有人在做，说明需求开始被命名）

### 竞品 7：家教与新型 AI 陪练产品

**概况**：包括大学生家教、线上一对一（合规受限），以及**可能出现的、以 AI 陪练为形态的新玩家**。

**产品优势（家教）**：
- 真人互动，能即时回应
- 家长对「有人管」有确定感

**产品劣势（家教）**：
- **成本高**：一对一按小时计费，高频使用不现实
- **供给受政策限制**：学科类培训被严管
- **质量不稳定**：大学生家教的水平参差
- **频率受限**：一周一两次，无法解决「每天做作业时的读题问题」

**新型 AI 陪练产品的威胁**：
- **技术门槛不高**：本产品的所有技术能力都建立在公开可用的模型之上（见「02-SWOT分析」T13）
- **一旦品类被验证，跟进的成本很低**——这是本产品必须认识到的一件事：**产品本身没有技术壁垒，唯一的壁垒是时间与用户积累**
- 但也正因为如此，**先进入并建立品类认知的价值很高**

**竞争威胁**：⭐⭐（中低，但**未来 12—24 个月可能上升**）

**本产品的应对**：
1. **在品类认知建立之前，速度比完美重要**
2. **尽快开始积累错题画像数据**——这是唯一无法被快速复制的东西
3. **建立教师口碑网络**——这也是时间壁垒

**关键动态追踪**：
- 是否出现定位相似的「审题训练」产品？（最直接的信号）
- 是否有产品开始主打「不给答案」？
- 教师社群中是否开始讨论「审题要单独练」这个话题？

**关于免费试用力度的一个判断：**

与 B 端产品不同，本产品的边际成本几乎为零，**因此可以给出远比常规更慷慨的试用**。
建议**首次完整陪练完全免费、不限题数、但只限首次**。理由：

- 本产品最大的障碍是**家长不知道「审题训练」是什么**——不让他完整体验一次，他一辈子不会懂
- 本产品最大的风险是**用户根本不会来第二次**——第一个月的数据比第一个月的收入重要得多
- 边际成本极低，免费放量的代价很小

**这是本产品在定价上唯一可能形成的优势：别人不敢免费的东西，它敢。**

## 五、竞品轨迹分析（12—24 个月展望）

### 通用 AI 助手

**当前定位**：通用对话式助手，免费，已具备拍照识图与讲解能力。

**12 个月轨迹（2026.Q4 — 2027.Q3）**：
- 基础模型能力继续提升，数学推理与多模态识图更稳定
- **关键不确定性**：是否推出面向学生的「学习模式」——例如默认不给答案、先提问再解答
- 家长管控类功能可能出现（使用时长限制、内容过滤），这会削弱家长对「给设备」的顾虑
- 免费策略大概率维持（获客阶段的必然选择）

**24 个月轨迹（2027.Q4 — 2028.Q3）**：
- **最需要警惕的信号：出现「不给答案的学习模式」**。一旦通用 AI 提供这种模式，
  本产品在「不代答」这一点上的差异化会被大幅削弱——**因为它的免费版本也做得到**
- 通用 AI 做「学科训练流程」的动机仍然不强：为不到 1% 的使用场景做专项流程设计，ROI 不匹配
- 更可能的路径：通过「自定义提示词 / 角色设定」让用户自己搭出类似效果

**对本产品的启示：**
- **不要把差异化押在「不给答案」这一条上**——它是本产品的立场，但不是一个能守住的壁垒
- 真正难被替代的是**结构化的判定**（句子类型、条件句三级）与**长期画像**——
  这两件事需要一套预设的流程与持续的记录，通用 AI 的自由对话形态天然不适合
- **建议：尽早积累画像数据**。这是唯一一条「通用 AI 即使想做也要从头开始」的路

### 拍照搜题类

**当前定位**：学生端拍照获取答案与解析。

**12 个月轨迹**：
- 政策压力持续（拍照搜题受到明确限制）
- 可能向「练习」和「错题本」方向转移重心，减少对「直接给答案」的依赖
- **需要警惕**：它们可能推出「引导模式」或「不给答案模式」以应对监管——**这会直接侵占本产品的定位**

**24 个月轨迹**：
- 如果监管进一步收紧，这类产品的商业模式会被迫调整
- 凭借已有的用户规模，它们做「审题引导」的分发效率远高于本产品——
  **这是本产品最需要警惕的「降维打击」场景**

**对本产品的启示：**
- 不要把「形态相似」当作优势，要把「逻辑相反」讲清楚并反复讲
- 如果这类产品开始做引导模式，本产品唯一能守的是**方法的专业性**（一套完整的审题方法论 vs 临时的引导话术）

### 学习机厂商

**当前定位**：硬件 + 内容 + AI 讲题的组合。

**12 个月轨迹**：
- 硬件与内容继续迭代，AI 能力从「讲题」向「诊断」缓慢延伸
- 可能出现「学习习惯」「学习方法」类的新功能模块——**这是本产品最需要盯的方向**

**24 个月轨迹**：
- 如果「审题训练」被验证有价值，学习机厂商是最有可能把它做成一个模块的力量
  （它们有硬件、有渠道、有家长信任）
- 但它们做这件事的深度受限：**审题训练需要逐题解剖，而硬件产品的逻辑是标准化内容**

**对本产品的启示：**
- 学习机厂商是**潜在的渠道伙伴而非首要对手**——如果它们需要「审题训练」能力，
  本产品的方法论与积累可能是它们想要的东西
- 但也要认识到：**一旦它们下场，本产品在 C 端的独立生存空间会被显著挤压**

### 题库练习类

**当前定位**：题量 + 错题本 + 练习推荐。

**12 个月轨迹**：
- 错题本从「题目集合」向「能力分析」升级是自然方向，**这会对本产品的画像功能形成压力**
- 但它们的分析维度是「知识点」，而本产品的维度是「审题环节」——**两者不重合**

**24 个月轨迹**：
- 大概率仍以「练够量」为核心，不太可能转向「训练过程能力」
- 它们的动力来自用户规模，而审题训练的用户规模看起来不大

**对本产品的启示：**
- **本产品可以主动承认练习量的价值**：审题训练不替代刷题，它解决刷题替代不了的那个问题
- 这个表态能减少与整个练习类生态的对抗感

### 家长自己辅导 / 免费讲题内容

**这两类的轨迹非常稳定：不会变化。**

- 家长仍然会自己讲，仍然会讲不清、会发火
- 免费内容仍然免费，仍然解决「别人的题」

**对本产品的启示：** 这两类对手不会变弱，也不会变强。
**本产品能否赢，取决于能不能让家长承认「这件事我自己做不好」**——这是全部冷启动难度的核心。

### 可能出现的新玩家

**这是最需要跟踪、也最难预判的一类。**

| 信号 | 含义 | 应对 |
|------|------|------|
| 出现「审题训练」定位的产品 | **品类被验证**——好消息与坏消息同时到达 | 立即评估差异化是否还在 |
| 有产品开始主打「不给答案」 | 本产品的核心立场被复制 | 靠方法论深度与积累数据拉开差距 |
| 内容平台上出现「审题要单独练」的讨论 | **品类认知正在形成**——最重要的正面信号 | 立即进入这些讨论，建立关联 |
| 教师社群开始讨论审题教学 | 本产品最理想的传播土壤 | 第一时间参与并提供工具 |

**判断**：如果本产品能验证「家长愿意为审题训练付费」，**12—24 个月内出现模仿者几乎是必然的**——
因为技术门槛不高（见第三章第 50 项）。**时间窗口不长。**

## 六、赢 / 输场景分析

### 6.1 vs 通用 AI 助手（最重要的一场）

#### 赢的场景

| 场景 | 本产品赢的关键因素 | 发生概率 |
|------|-----------------|---------|
| 家长担心孩子用 AI 抄答案 | 本产品明确不给答案 | 高 |
| 家长希望看见「孩子在使用」的证据 | 本产品有错题记录，通用 AI 没有 | 高 |
| 家长希望孩子被「盯着练」而不是「随时问」 | 本产品是结构化流程，通用 AI 是自由对话 | 中高 |
| 学生被通用 AI 直接给出答案后失去思考意愿（家长的观察） | 引导式 vs 代答式 | 中 |
| 需要长期的卡点画像 | 通用 AI 无记忆 | 中高 |

#### 输的场景

| 场景 | 本产品输的关键因素 | 发生概率 |
|------|-----------------|---------|
| 家长自己先试了通用 AI，觉得「够用了」 | 免费 + 已在手机里 | **高** |
| 学生想要答案而不是被提问 | 通用 AI 满足得更快 | **高** |
| 家长觉得「都是 AI，为什么要花钱」 | 品类认知缺失 + 价格敏感 | **高** |
| 通用 AI 推出学习模式 | 差异化被削弱 | 中 |
| 家长不认为自己孩子「审题有问题」 | 品类认知缺失 | **高** |

#### 赢的策略

1. **不做功能对比，做一次现场演示**。不要列功能表，而是**让一位家长亲眼看他自己的孩子被提问**。
   通用 AI 的优势在于看起来什么都行，本产品的优势在于**在具体一个孩子身上的具体表现**——
   这个差别只能在演示里被看见
2. **把「不给答案」讲成一件家长能理解的事**：不是「我们不给你答案」，而是
   「**给的答案越多，他自己想的越少**」
3. **主动承认通用 AI 的价值**：「平时问问题很好用。但它替代不了有人盯着他把题读完。」

### 6.2 vs 家长自己辅导（份额最大的一场）

#### 赢的场景

| 场景 | 本产品赢的关键因素 |
|------|-----------------|
| 家长已经辅导到「一讲就吵」的阶段 | 不会发火——这句话的转化力最强 |
| 家长发现初中应用题自己已经讲不动 | 不需要家长懂知识 |
| 双职工家庭，放学后无人辅导 | 学生可独立使用 |
| 家长想知道「到底卡在哪」，而不是自己猜 | 错题画像给出具体判断 |

#### 输的场景

| 场景 | 本产品输的关键因素 |
|------|-----------------|
| 家长认为「我自己讲就行了，何必花钱」 | 零成本诱惑 |
| 家长不愿意承认自己讲不了 | 面子问题 |
| 家长认为「我小时候就是这么学的」 | 路径依赖 |
| 孩子更愿意问家长而不是一个 AI | 情感连接无法被替代 |

#### 赢的策略

1. **不与家长竞争「讲题」，与家长竞争「不发火、讲得清楚」**——把产品定位为家长力所不能及那一段的补位，
   而不是家长的替代者。**这个定位既更容易被接受，也更接近事实**
2. **用家长自己的话**：「讲了八百遍还是错，最后两个人都生气」——这句话本身就是最好的文案
3. **明确说「不需要你懂知识」**——很多家长没说出口的顾虑正是这个

### 6.3 vs 拍照搜题类（这不是产品之争，是归类之争）

**这一场不是争夺用户，而是争夺定义权。** 本产品与它的关系里，最危险的不是输掉用户，
而是**被归到同一类里去**（见「01-PESTLE宏观环境分析」P1、「02-SWOT分析」T1）。

| 情景 | 结果 | 触发条件 |
|------|------|---------|
| **区隔成功** | 本产品被认为是一类新东西 | 前三秒的自我澄清有效；「不给答案」被看见 |
| **区隔失败** | 被归类为搜题工具，承担品类污名 | 界面与文案没有讲清楚；或行业出现相关负面事件 |

#### 赢的策略

1. **形态上区隔，而不是文字上解释**：产品里没有「答案」这个入口，学生写完解答才有点评。
   **形态比文字有用十倍**
2. **准备一页纸的差异说明**，在产品上线前就写完
3. **把「不给答案」做成可传播的内容**——它是差异化最强的证据，也天然适合在家长群中转发

## 七、蓝海机会地图

将「用户痛点强度」与「竞品覆盖度」交叉分析后识别出的机会区域。

### 蓝海 1：「审题训练」这个品类本身

- **痛点强度**：高（「读完就动笔、老漏条件」是普遍现象，家长与老师都观察得到）
- **竞品覆盖度**：**0** —— 无任何产品以此定位
- **机会**：成为这个品类的定义者
- **差异化阻力**：**极高** —— 不是因为技术难，而是因为**需求尚未被命名**

**这是本产品的主战场，也是最难的一块**：竞品覆盖度为零，不是因为它难做，
而是因为**没有人确认过这个需求值不值钱**。

### 蓝海 2：家长可读的「过程记录」

- **痛点强度**：高（家长想知道孩子到底卡在哪，而不是只知道分数）
- **竞品覆盖度**：低（学习机有学习报告，但维度是「知识点掌握度」而非「审题环节」）
- **机会**：一份指向**能力环节**而不是**知识内容**的报告——
  「这道题他漏了一个隐含条件」而不是「一次函数掌握度 72%」
- **差异化阻力**：中（需要长期数据积累才能说出规律）

### 蓝海 3：教师可用的审题教学素材

- **痛点强度**：中高（教师知道学生读题有问题，但没有工具可教）
- **竞品覆盖度**：**0**
- **机会**：把审题方法论做成课堂可用的素材，让教师能直接用一节课讲「怎么读一道应用题」
- **差异化阻力**：低（技术门槛不高），但**变现困难**（教师在 C 端不付费）
- **真实价值**：**这是获取教师推荐的入口**——工具免费给教师用，换来的是他们的推荐

### 蓝海 4：学生端的「不给答案」对话

- **痛点强度**：中高（家长担心孩子用 AI 抄答案，这是一个真实且普遍的心结）
- **竞品覆盖度**：极低（通用 AI 默认给答案；学习机的定位是「讲清楚」）
- **机会**：一个**明确拒绝代答**的学习工具——它把家长的顾虑变成了产品特征
- **差异化阻力**：**低**（容易被复制），但**先发者有定义权**

### 蓝海 5：变式题验收机制

- **痛点强度**：中（家长隐约知道「做完这道题不代表会了」，但无法验证）
- **竞品覆盖度**：低（题库有「同类题推荐」，但那是练习逻辑，不是验收逻辑）
- **机会**：「换一道还能做出来才算真会」——把不可验证的「学会」变成可观察的现象
- **差异化阻力**：中（生成 + 校验的技术门槛存在，且质量不稳定）

### 蓝海热力图

```
                          竞品覆盖度 →
                    低                中                高
             ┌─────────────────┬─────────────────┬─────────────────┐
        高   │ 🔵 审题训练品类  │                 │                 │
        │   │ 🔵 家长过程记录  │                 │                 │
   痛    │   │                 │                 │                 │
   点    │   ├─────────────────┼─────────────────┼─────────────────┤
   强    │   │ 🔵 教师教学素材  │ 🔵 变式题验收    │                 │
   度    │   │                 │                 │                 │
   │     │   ├─────────────────┼─────────────────┼─────────────────┤
        │   │ 🔵 不给答案对话  │                 │                 │
        │   │                 │                 │   (饱和区：       │
    低   │   │                 │                 │    讲题/搜题/刷题)│
             └─────────────────┴─────────────────┴─────────────────┘
```

**热力图读出来的最重要一件事**：**本产品的五个蓝海全部落在左半边**（竞品覆盖度低或为零）。
这说明**定位是准的**——它确实在做别人没做的事。

**但也暴露了同一个问题**：**五个蓝海全部集中在「痛点强度」的高/中区域，
却没有一个落在「已被验证的需求」区域。** 整个地图的左半边是一片空白，
而**空白既可能是蓝海，也可能是无人区**。

## 八、护城河可持续性分析

### 本产品的六条「可能的护城河」及其真实强度

> 这一节的评估比同类文档中要悲观得多，因为本产品的处境确实如此：**它几乎没有结构性壁垒。**

| 护城河 | 当前强度 | 可持续性 | 被侵蚀的条件 |
|--------|---------|---------|------------|
| **1. 屏幕标记 + 即时判定** | 中 | **低（< 1 年）** | 任何有开发能力的人拿到同样的模型都能做出来 |
| **2. 审题方法论（四类句 / 三级条件）** | 中 | **低** | **方法论来源是收集而非原创**，别人同样可以获得；且它不是技术，无法专利化 |
| **3. 错题画像数据积累** | 低（刚起步） | **中高（2—3 年）** | **唯一像样的护城河**——竞品要复制必须从头定义维度并等待同样长的积累周期 |
| **4. 成本结构极低** | 强 | **低** | API 价格普降会抹平相对优势；且低价本身不是壁垒 |
| **5. 「不给答案」的产品伦理** | 强 | **不适用** | **它是合规资产，不是商业护城河**——竞品可以一夜之间也选择不给答案 |
| **6. 教师口碑网络** | **零（尚未开始）** | **中高（2—3 年）** | 需要时间，且无法用钱加速——但一旦形成极难被夺走 |

### 残酷的结论

**本产品真正能称得上「护城河」的只有第 3 条和第 6 条，而它们共同的特征是：
都没形成，都需要时间，都无法用钱加速。**

这意味着两件事：

1. **产品本身没有壁垒，先发的时间窗口很短**（估计 12—24 个月，一旦品类被验证，模仿者会迅速出现）
2. **唯一值得投入的长期资产，是「积累」本身**：用户的错题记录、教师的关系。
   **这两件事应当在产品能跑通的第一天就开始做，而不是等产品完善之后**

**一个必须接受的判断**：如果本产品最终失败，原因大概率不是「被竞品打败」，
而是**「没有在窗口期内积累出任何别人拿不走的东西」**。

### 各竞品的护城河及被突破点

| 竞品 | 核心护城河 | 被突破点 |
|------|----------|---------|
| 通用 AI 助手 | 免费 + 规模 + 模型能力 | 不做结构化训练流程；无长期记忆 |
| 家长自己辅导 | 零成本 + 天然信任 + 随时可用 | 讲不清、会发火、初中以后讲不动 |
| 拍照搜题类 | 用户规模 + 题库 | 品类污名 + 政策限制 + 不训练过程 |
| 学习机 | 硬件信任 + 渠道 + 内容 | 重讲题轻过程、客单价高、内容更新慢 |
| 题库练习类 | 题量 + 使用习惯 | 逻辑是「多做题」而非「改方式」 |
| 免费讲题内容 | 免费 + 传播力 | 不是学生自己的题、无互动、无反馈 |

## 九、合作机会矩阵

> **说明**：与同类文档相比，本产品可合作的对象明显更少——**没有学校渠道、没有平台方、
> 没有可嵌入的 B 端系统**。以下是仅有的几条路径。

| 合作方 | 合作方式 | 优先级 | 双方收益 | 风险 |
|--------|---------|--------|---------|------|
| **一线数学教师 / 教研组** | 免费提供工具与课堂素材，换取推荐与反馈 | ⭐⭐⭐⭐⭐ | 教师获得教学工具；本产品获得**唯一不需要品类教育的渠道** | 依赖个人意愿，不可规模化 |
| **教育类内容创作者**（数学博主 / 公众号） | 提供方法内容与产品体验，换取曝光 | ⭐⭐⭐⭐ | 创作者获得素材；本产品触达家长 | 内容质量与账号调性需匹配 |
| **微信生态**（小程序 / 社群工具） | 以小程序形态进入家长日常使用场景 | ⭐⭐⭐⭐ | 微信丰富生态；本产品获得分发 | 平台规则依赖 |
| **教辅出版方** | 授权审题方法论，嵌入教辅 | ⭐⭐ | 出版数字化；本产品获得曝光与少量授权收入 | **需先厘清方法论来源**（见 W12） |
| **师范院校 / 区县教研室** | 作为师范生实习与教研的工具 | ⭐⭐⭐ | 院校获得新工具；本产品从源头建立认知 | 见效慢（2—3 年） |
| **学习机厂商**（长期） | 提供审题训练能力模块 | ⭐⭐ | 厂商补齐短板；本产品获得分发 | 被吸收后失去独立性 |

**合作策略的核心判断：本产品最值得投入的合作对象是「教师」，而不是任何机构。**

理由：教师是**唯一一个不需要被教育「审题需要单独练」的群体**（见「02-SWOT分析」O8）。
在其他所有渠道都要先支付品类教育成本的情况下，教师推荐的边际成本几乎为零。

### 11.3 战略优先级（基于竞争分析）

| 优先级 | 行动 | 理由 |
|--------|------|------|
| **P0** | **验证判定可靠性**（条件句三级准不准） | 判定不准则整个产品不成立。这是所有行动的前置条件 |
| **P0** | **做出可试用版本 + 三秒澄清设计** | 在只有一屏可用流程时就去试，比在完整产品上失败便宜得多 |
| **P0** | **争取 3—5 位一线教师认可** | 唯一不需要支付品类教育成本的渠道；同时能验证「审题值得单独练」这个前提 |
| P1 | **从第一天开始积累错题画像数据** | 唯一可能形成的长期壁垒；越早开始越好，且结构定下来就不该改 |
| P1 | 微信小程序 | C 端最自然的入口；缺失是结构性的 |
| P1 | 变式题的生成与自校验闭环 | 产品的验收机制，质量不过关会直接损害信任 |
| P2 | 处理方法论来源与署名口径 | 成本不高，但拖到有用户后再处理代价大得多 |

| P3 | 评估学段扩展（八、九年级）的可行性 | 解决生命周期只有一年的结构性问题，但技术难度显著上升 |
