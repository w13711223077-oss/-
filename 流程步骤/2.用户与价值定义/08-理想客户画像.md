# 理想客户画像（ICP）— 数学审题逐题陪练系统

> 市场：中国 K12 AI 辅助学习工具（C 端 · 学生 / 家长付费）
> 学段：初中七年级 · 应用题
> 日期：2026 年 9 月

> **关联文档**：`06-用户画像`（人物）、`07-价值主张`（价值与切换成本）、`01-PESTLE`（家庭结构与分层）、`03-市场规模`（主战场与定价）
>
> **数据口径**：本文中的比例、金额、周期均为**估算或主观判断**，未经核实。产品尚未开发，所有「验证」均为**待执行**。

> ### 与 B 端 ICP 的根本差别（读全文前先知道这一条）
>
> 常规 ICP 描述的是**采购单位**（学校、部门、企业），有画像、有决策链、有采购流程。
> **本产品的付费单位是一个家庭，决策者是一个人，决策周期是数分钟。**
>
> 这意味着：**本产品没有「销售」这个动作，也没有「采购」这个环节。**
> 唯一的转化动作是**第一次体验**——**决策在体验结束前就已经发生**。
> 全文的每一个判断都建立在这条差别上。

## 一、ICP 核心定义

### 一句话 ICP

> **二线及地级市的双职工家庭；孩子读七年级、数学中游（70—85 分）而应用题是主要失分点；家长亲自辅导过、但已经讲不动了；家里有一个孩子能用的设备；家长活跃于微信家长群，且有为线上服务付费的习惯。**

### 为什么是这个 ICP

| 维度 | 选择逻辑 | 排除逻辑 |
|---|---|---|
| **七年级** | 审题能力的窗口期——算术思维转代数思维的转折点，**纠正成本最低**（`01`·S2）；同时家长「还来得及、必须现在抓」的意识开始建立 | 八、九年级不覆盖（产品设定）；小学阶段思维形态不同 |
| **二线 / 地级市** | **付费意愿与能力的平衡点**；可选方案有限；家长主要通过微信社群获取教育信息——与本产品唯一的低成本传播路径契合（`03`·3.3） | 一线城市产品竞争密度与家长挑剔度显著抬高冷启动难度；县城以下付费转化率低 |
| **数学中游（70—85 分）** | 这个区间的孩子**「会算但读不懂」最典型**；且**提分空间肉眼可见**，家长有理由相信投入有用 | 稳定 90+ 的孩子不需要；60 分以下应先解决更基础的问题 |
| **家长辅导已失效** | **这是全表最强的一个判别信号**——不是「孩子数学不好」，而是「我讲不动了」或「一讲就吵」（`01`·S4） | 家长完全不参与（不会付费）；家长乐于且有能力辅导（不需要产品） |
| **有一个可用的设备** | 「学生独立使用」是产品形态的前提 | 家里只有家长手机、且使用被严格控制 |
| **微信获取教育信息** | C 端**唯一的低成本触达路径**（`03`·六 渠道可行性排序） | 不活跃于任何家长社群的家庭，只能靠投放触达——**而投放的 LTV/CAC = 1.9，经济上不成立** |

## 二、ICP 详细画像

### 2.1 家庭画像（付费单位）

| 维度 | ICP 描述 | 排除标准（NOT ICP） | 判别方法 |
|---|---|---|---|
| **城市层级** | 二线城市或地级市市区 | 乡镇 / 县城（付费转化率低） | 家庭住址 |
| **家庭结构** | 双职工；孩子由父母照料 | 完全隔代抚养（祖辈不会看记录、不会付费） | 直接询问 |
| **家庭可支配年收入** | 中等（**估算** 8—25 万元） | 极端两端——过高（选择太多、要求苛刻）或过低（无线上付费习惯） | 推断（设备、消费习惯） |
| **线上付费习惯** | **有**——用过会员 / 订阅服务 | 从未为线上服务付过费（说服成本极高） | 询问「有没有买过 App 会员」 |
| **设备条件** | 家里有平板，或孩子有可用的手机 | 家里无设备；或设备完全由家长掌控且严格限时 | 直接询问 |
| **家长教育程度** | 大专至本科，**但数学知识已失效** | 家长是数学教师或理工科背景且仍在辅导（不需要产品） | 直接询问 |
| **信息渠道** | 微信家长群、朋友圈 | 不参与任何社群 | 直接询问 |
| **对「过程 vs 分数」的态度** | 认可「先把题读懂」这件事的价值 | **只认分数**——一个月没涨分就判断无效（反画像 C） | 询问「你怎么判断一个工具好不好」 |

### 2.2 学生画像（使用单位）

| 维度 | ICP 描述 | 说明 |
|---|---|---|
| 年级 / 年龄 | 七年级，12—13 岁 | 紧邻《中小学生成式人工智能使用指南》中「小学禁止独自使用 AI」的限线（`02-SWOT` T1） |
| 成绩区间 | 数学 70—85 分（100 分制），**应用题是主要失分点** | 不是不会算，是没读懂 |
| 作业习惯 | 按时完成、字迹工整 | 他不是不学的孩子——**这一点很重要**，产品训练的是方法而不是态度 |
| 设备操作 | 会拍照、会点选；**打字慢** | 直接决定了 ④ 开放回答是全流程摩擦最大的一步 |
| 使用频率 | 每周 2—3 次（卡住时才打开） | **不是每天**——任何按「日活」设计的机制在这里都是错的 |
| 触发方式 | 被动（家长或教师引导） | 他不会自己找这个产品 |

### 2.3 决策流程画像

**这一节是 C 端 ICP 与 B 端 ICP 差别最大的地方。**

| 维度 | 本产品（C 端） | 对照：一个 B 端工具的典型情况 |
|---|---|---|
| **决策路径** | **家长一人决定**，没有审批链 | 备课组长 → 教研主任 → 副校长 → 校长 → 总务处 |
| **关键影响者** | 教师（若推荐）、孩子的即时反馈、家长群里的口碑 | 教研主任、分管副校长 |
| **决策周期** | **数分钟到数天** | 2—4 个月（良好关系下 2—4 周） |
| **决策驱动** | 「**能不能解决我家孩子这个问题**」 > 功能列表 > 价格 | 案例与数据 > 功能列表 > 价格 |
| **最大的阻力** | **不确定有没有用**；孩子的接受度；已有免费替代 | 品牌缺失；实施顾虑；ROI 不明 |
| **预算额度** | 月度数十元（**估算**）——**低于「需要和配偶商量」的门槛** | 3000—8000 元/班/年 |
| **需要准备的销售材料** | **几乎没有**——她不会看 PPT | 案例、白皮书、报价方案、向上汇报模板 |

**这张表最重要的一行是「决策周期：数分钟」——它推翻了整个转化逻辑：**

> **在产品还没有第二次被打开之前，付费决策可能已经做完了。**
> 所以本产品要准备的不是「销售流程」，而是**第一次体验本身**。
> **第一次体验不是销售的前奏，它本身就是销售。**

## 三、ICP 的 JTBD（家庭视角）

### 功能型 JTBD

> 当孩子在晚上做作业卡住时，**让他自己把这道题读懂，并且不用喊我。**

**成功标准**：
- 孩子能独立走完一次完整陪练（中途不求助）
- **首体验（S1–S8）≤ 15 分钟**；完整闭环只记录（现状是 10—30 分钟，且常常失败）
- 家长一周里被问的次数明显变少

### 情感型 JTBD

> **不再因为讲题跟孩子吵架。**

**成功标准**：
- 晚上不再出现「我不是刚讲过了吗」这类对话
- 孩子不会因为一次争吵而不再求助

### 社会型 JTBD

> 在家长群里，**不做那个别人讨论方法时自己什么都答不上来的人**。

**成功标准**：
- 别人问「要不要报补习班」时，她能说出一句有内容的话
- 这句话不是说分数，是说**问题在哪一类**（`06`·王丽华一周节奏 周五 12:30）

### 学生侧的 JTBD（家庭 ICP 内部的使用者）

> 卡住时，**知道自己该从哪儿下手**——不是拿到答案，是读懂这道题在问什么。

**成功标准**：能说出「我这次是漏了一个隐含条件」，而不是「我数学不好」。

## 四、ICP 痛点深度量化

| 痛点 | 当前做法 | 程度 | 定量影响 | 替代方案的成本 |
|---|---|---|---|---|
| **晚间辅导失效** | 家长亲自讲，讲两三遍后以发火结束 | 🔴 **极高** | 每晚 10—30 分钟；**一学年约 200 个晚上**（估算） | 报补习班：**估算** 每课时百元量级；且不确定对不对症 |
| **讲不清「为什么这么想」** | 家长即使会做，也说不清思路 | 🔴 极高 | 这是「讲不动」的**真正原因**——会做和会教是两件事 | 无替代：请一对一（贵且合规受限） |
| **孩子不再求助** | 一次争吵之后，他宁可瞎试或抄答案 | 🔴 极高 | **问题被掩盖而不是被解决**，代价在一学期后显现 | 无替代 |
| **信息黑洞（不知道卡在哪）** | 只看到分数；问孩子只说「就是不会」 | 🟠 中高 | 无法判断该不该干预、怎么干预 | 问老师（回复慢且笼统）；看排名（徒增焦虑） |
| **无效教育支出** | 打听补习班、买过教辅，翻两页就放下 | 🟠 中高 | **不确定的花钱**——比不花钱更消耗信心 | 报班（**估算** 每课时百元量级，方向可能是错的） |
| **孩子的「认真读题」无具体动作** | 反复叮嘱「要仔细」「要认真」 | 🟠 中高 | 一句正确的废话重复了几年，**从没有人给过可执行的动作** | 无替代 |

**这张表的读法**：**前三条（辅导失效、讲不清、孩子不再求助）是同一条链上的三个环节**，而它们的共同解法只有一个——**把「讲」这件事从家长身上移走**。这是 ICP 最核心的诉求，也是产品存在的位置。

## 五、定量 ICP 评分模型

### 5.1 评分维度与权重

| 维度 | 权重 | 评分标准 |
|---|---|---|
| **家长辅导现状** | **25%** | 已尝试辅导但失效 = 10；想辅导但没时间 = 8；从没辅导过 = 5；仍在有效辅导 = 0 |
| **学生成绩区间** | 15% | 70—85 分 = 10；60—70 或 85—90 = 7；< 60 或 > 90 = 3 |
| **城市层级** | 15% | 二线 / 地级市 = 10；新一线 = 8；一线 = 6；县城 = 4；乡镇 = 1 |
| **线上付费习惯** | 15% | 有多次订阅经验 = 10；有过 = 8；从未 = 2 |
| **家长参与度**（会不会看记录） | 15% | 会主动看、会问 = 10；偶尔看 = 6；完全不管 = 0 |
| **设备条件** | 10% | 孩子有专属平板 = 10；可借用家长手机 = 6；无 = 0 |
| **对「过程」的认可度** | 5% | 认可「先读懂」的价值 = 10；中立 = 5；只认分数 = 0 |

> **权重最大的是「家长辅导现状」（25%），而不是「孩子成绩」——这是刻意的。**
> 因为驱动付费的不是「孩子数学不好」，而是**「我试过了，我不行」**。
> 一个孩子考 70 分但家长从没管过，和一个孩子考 80 分但家长已经讲到发火——**后者才是 ICP。**

### 5.2 评分与分级

```
ICP Score = Σ(维度得分 × 权重)

>= 8.5 : Tier 1（最高优先级）
7.0—8.4 : Tier 2（高优先级）
5.0—6.9 : Tier 3（低优先级，不主动拓展）
< 5.0  : NOT ICP（不投入资源）
```

## 六、ICP 的分层

### Tier 1（最高优先级）

**画像**：二线 / 地级市双职工家庭；孩子七年级数学 70—85 分；**妈妈已经讲过、且讲到发火**；会用微信家长群；有线上订阅经验；家里有平板。

**阶段目标数量**（**估算**，随验证推进）：

| 阶段 | 目标 | 说明 |
|---|---|---|
| P1 验证批次 | **3—5 个家庭** | 不收费，只拿到真实反馈（`02-SWOT` P1） |
| 首批付费 | **30—50 个家庭** | 教师推荐带来的第一波 |
| 12 个月内 | **100—300 个家庭** | 对应 `03`·2.2 的悲观—基准区间 |

**服务策略**：
- **创始人（当前唯一执行者）亲自跟每一个**——这个阶段数量小，能做的服务深度是最高的
- **重点不是「教怎么用」，是「看第一次会不会卡住」**
- 与每个 Tier 1 家庭确认两件事：孩子有没有第二次打开、家长能不能说出产品在做什么

### Tier 2（高优先级）

**画像**：一线城市；或孩子成绩略高于 / 低于最优区间；或家长参与度中等；或设备条件一般。

**策略**：**不主动拓展，但转介绍进来就接。** 因为这一层的转化率与留存都未经证实，**在种子期把资源分给它们，等于稀释了 Tier 1 的样本质量**。

### Tier 3（低优先级）

**画像**：县城 / 乡镇；付费敏感但学习焦虑同样强烈。

**策略**：**这一层是 `03`·8.3 悲观情景里唯一可能撑住规模的地方**，但它需要低价或免费增值的产品形态——**而那个形态现在还不存在**。**在解决「产品是否成立」之前，不碰这一层。**

## 七、负向 ICP（Negative ICP）— 谁不该碰

> 与 `06-用户画像` 中的「反画像」是同一条思路，但**这里给的是可当场判断的信号**。

| 负向 ICP | 原因 | 判别信号 | 如果已经在接触 |
|---|---|---|---|
| **家长完全不参与** | 没人看记录 → 没人付费、没人续费 | 「都是他爸/他自己弄，我不管」 | 礼貌结束。**产品做得再好也不会转化为收入** |
| **只认分数的家长** | 一个月内看不到分数变化就会判断无效 | 「能提高多少分？」「多久见效？」 | **主动说明不承诺提分**。宁可不成交，也不要一个必然失望的用户 |
| **孩子已稳定 90+** | 没有审题问题，或问题不足以驱动付费 | 成绩单 | 不投入 |
| **孩子基础过弱（< 60）** | 问题在更基础的地方，审题不是当前瓶颈 | 计算错误占多数 | 不投入——**先解决更前面的问题** |
| **学生明确抵触、被逼着用** | 产品的核心前提是学生配合（要写出隐含条件、要自己写解答） | 「他根本不听我的」 | 不投入。产品**不能对抗使用者的意愿**——这是形态决定的 |
| **已经在用一对一且满意** | 替代成本高，且家长已有更信任的方案 | 「我们请了老师」 | 保持联系，但不硬推 |
| **「免费党」** | 不是没钱，是「能免费绝不付费」 | 「有没有免费版？」 | 不投入。本产品**不参与免费竞争**（对标的免费替代是通用 AI，赢不了） |
| **家里没有可用设备** | 学生独立使用是产品形态的前提 | 「他只能周末用我的手机」 | 暂不投入 |

### 快速筛查：5 个问题

**在与一个家庭接触的前 5 分钟，问这 5 个问题：**

| # | 问题 | 负向回答 | 正向回答 |
|---|---|---|---|
| 1 | 「孩子做应用题的时候，你一般会怎么做？」 | 「我不太管他学习」 | 「我讲啊，**讲到最后两个人都生气**」 |
| 2 | 「他读题的时候有没有什么让你头疼的地方？」 | 「他数学就是差」 | 「**读完就动笔，老漏条件**」 |
| 3 | 「你买过什么线上的东西吗？比如 App 会员？」 | 「没有，我不用那些」 | 「买过几个会员」 |
| 4 | 「孩子平时用什么做作业？手机还是平板？」 | 「就我的手机，我怕他玩」 | 「他有自己的平板」 |
| 5 | 「如果有个工具能让他自己把题读懂，你觉得怎么样？」 | 「能提多少分？」 | 「**那他不用天天喊我了**」 |

**判读**：≥ 2 个负向 → 需进一步评估；≥ 3 个负向 → NOT ICP。

**第 1 题和第 5 题是权重最高的两题**——它们分别命中「辅导已失效」和「要的是过程不是分数」，而这两条是 ICP 权重最大的两个维度。

## 八、ICP 客户旅程（C 端版）

> **与 B 端旅程的根本差别**：没有「采购」和「上线」这两个阶段。
> **决策在第一次体验期间就发生了**，之后是持续使用或流失，没有中间状态。

```
触发 ──→ 首次体验 ──→ 付费决策 ──→ 持续使用 ──→ 推荐
(数天—数周)  (20—45 分钟)  (数分钟—数天)  (数周)      (持续)
              ↑
        决策在这里发生
```

### 阶段 1：触发（谁先开口）

**家长在想什么**：「今天晚上又要讲题了」「上次讲完他就不理我了」

**触达方式**（按 `03`·六 的可行性排序）：
1. **一线教师推荐**——唯一不需要支付品类教育成本的渠道
2. **家长群口碑**——需要先有种子用户
3. 教育类内容——慢，且需要长期投入
4. ~~付费投放~~——**LTV/CAC = 1.9，不可行**

**关键指标**：从「听说了」到「愿意试一次」的比例。

**注意**：这一阶段**产品还没有参与**——触发完全发生在关系与内容层面。

### 阶段 2：首次体验（**全旅程最关键的一步**）

**家长在想什么**：「这到底是个什么东西？跟搜题有什么不一样？孩子会喜欢吗？」

**孩子在想什么**：「又让我做题。」

**产品要做的三件事**（按重要性）：

| 事项 | 目标 | 检验方式 |
|---|---|---|
| **① 三秒澄清** | 家长在 3 秒内判断「这不是搜题工具」 | 首屏不含「答案」入口；看完后能复述「它不给答案」 |
| **② 完整走通一次** | 学生独立走完：拍照 → 标注 → 写解答 → 点评 → 变式题 | 首次完成率 ≥ 70%（目标） |
| **③ 首体验时长** | **≤ 15 分钟（S1–S8）** | 产品计时；**首体验超过 20 分钟基本不会再来**；完整闭环另记 |

> ⚠️ **这三件事里，第 ③ 件目前是最大的风险点。**
> 按 `06-用户画像` 第二章推演的最长情形，**完整闭环**接近 **43 分钟**——但其中审题弧线（S1–S8）只占 17 分钟，写解答 12、批改 4、变式 9、收束 1。
> **15 分钟只约束首体验（S1–S8）**；S9 之后是「可选的后续」，不计入首体验（`11`·决策 1）。
> **如果首体验（不是完整闭环）超过 20 分钟**，转化仍会在第一步失败。

**关键指标**：首次完成率、首体验时长（S1–S8）。

### 阶段 3：付费决策

**家长在想什么**：「这个有用吗？值这个钱吗？孩子会一直用吗？」

**决策依据**（按权重）：
1. **孩子有没有走完一次、并且看起来不排斥**
2. **她能不能说出「它不给答案」**——这是「跟搜题不一样」的直接证据
3. 价格是否在「不需要商量」的区间内

**产品要做的**：
- **首次完整体验免费、不限题数**——边际成本在角分量级，免费放量的代价极小（`03`·十）
- **月付，不做年付**（用户生命周期最长一年 + 预付式消费合规）
- **定价锚点不要选「通用 AI = 0 元」**，要选「一次家教的钱」

**关键指标**：首次体验 → 付费的转化率。

### 阶段 4：持续使用（留存）

**家长在想什么**：「他还用吗？有没有变好？」

**产品要做的**：
- **每周一条记录**，30 秒能看完——**这是她唯一的触点，也是续费的全部依据**
- 记录要带**时间维度**（「这类题他这两周已经能自己找出来了」），单次记录没有价值

**关键指标**：次月续费率（**估算** 目标 60%，`03`·6.1 中唯一真正的杠杆）。

### 阶段 5：推荐

**家长在想什么**：「要不要跟群里的人说一句？」

**推荐的自然语言**（按 `06` 的推演）：
- 「你先别急着找补习班——**有个东西不给孩子答案**，就是让他自己把题读懂」
- 「**一个月一顿饭钱**」

**注意**：推荐的语言里**不会出现孩子的成绩**——因为产品本身没有排名，也因为她不会用孩子的成绩去推荐一个「训练方法」的东西。

**关键指标**：非熟人带来的新用户比例。

## 九、ICP 验证方法论

### 9.1 待验证的六个假设

| # | 假设 | 验证方法 | 通过标准 | 时间 |
|---|---|---|---|---|
| **H1** | 家长能意识到「审题」是一个独立的、需要单独训练的问题 | 向 30—50 位七年级家长描述产品，**观察他们是用问题提问，还是用产品提问** | 出现明显的对号入座（「我家就是这样」），而不是礼貌性的「挺好的」 | 开发前 |
| **H2** | 驱动付费的是「我讲不动了」，而不是「孩子数学不好」 | 访谈中询问「你为孩子数学做过什么」 | ≥ 4/5 位家长自述「**讲到最后两个人都生气**」这类具体经历 | 开发前 |
| **H3** | 学生愿意完成一次陪练 | 3—5 个家庭真实试用，记录完成率与退出位置 | 首次完成率 ≥ 70%；**没有学生在前 3 分钟内退出** | P1 |
| **H4** | **首体验（S1–S8）能压到 15 分钟以内** | 实测计时 | ≤ 15 分钟（绿色线）；**> 20 分钟视为失败**（与 `07` 红线对齐）；完整闭环另记 | P1 |
| **H5** | 家长能说出「它不给答案」 | 体验后请家长用自己的话描述产品 | ≥ 80% 的家长提到这一点 | P1 |
| **H6** | 次月续费率能撑住 | 首批付费用户 30 天 / 90 天留存 | ≥ 60%（**估算**目标） | 付费后 1—3 个月 |

**这六条里，H4 是当前最没有把握、也最容易被绕过的一条**——因为它是一个工程问题（把流程压短），而不是一个认知问题。**而它一旦失败，H3、H5、H6 全部不会发生。**

### 9.2 验证访谈提纲（家长版，30 分钟）

**Part 1：现状（10 分钟）**

1. 「孩子做作业的时候，你一般在做什么？」
2. 「他什么时候会喊你？喊你之后会发生什么？」
3. 「你觉得他在数学上最让你头疼的是什么？」
4. 「关于这个，你试过什么办法？结果怎么样？」

> **第 2 题是关键**——它会自然引出「讲到最后两个人都生气」这个信号，而**这个信号比任何问卷题都更能判断 ICP**。

**Part 2：体验（10 分钟）**

5. 「刚才你看到孩子在用的时候，你觉得这是个什么东西？」
6. 「它没有给他答案——你注意到了吗？你觉得这样怎么样？」
7. 「你觉得他会愿意再用一次吗？为什么？」

> **第 5、6 题是在测「三秒澄清」是否有效**——如果家长答不出「它不给答案」，首屏设计就失败了。

**Part 3：价值与付费（10 分钟）**

8. 「如果它明天没了，你会怎么样？」
9. 「你觉得这个东西值多少钱一个月？」
10. 「你会跟群里的其他家长说吗？你会怎么说？」

> **第 10 题的目的不是测推荐意愿，是拿到「推荐原话」**——那句话就是之后所有对外文案的素材。
> **注意**：不要问「你会推荐吗」（所有人都会说会），要问「你会怎么说」。

### 9.3 感知数据 vs 行为数据的交叉分析

> **这一节对本产品比对 B 端更重要**——因为 C 端的反馈几乎全部来自家长的口头感受，而口头感受是最不可靠的数据。

| 验证维度 | 感知数据（家长说） | 行为数据（系统记录） | 一致性判断 |
|---|---|---|---|
| 孩子愿不愿意用 | 「他挺喜欢的」 | 首次完成率、数日内回访率 | **回访率 < 15% → 礼貌性好评** |
| 懂没懂产品 | 「挺好的，很智能」 | 能否复述「它不给答案」 | **说不出来 → 定位表达失败** |
| 有没有用 | 「感觉有帮助」 | 记录里是否出现「卡点收敛」 | **连续 4 周卡点不变 → 客气话** |
| 会不会续费 | 「会一直用」 | 30 天 / 90 天实际付费留存 | **说会但 30 天流失 → 礼貌性好评** |
| 孩子有没有进步 | 「读题细了」 | 变式题通过率的变化 | **无变化 → 观察偏差** |

**最重要的判断规则**：**家长的口头评价与行为数据不一致时，一律以行为数据为准。**
在 C 端，「挺好的」是最廉价的一句话——**它意味着没有任何具体信息**。

## 十、三类 ICP 的客户案例（假想，基于已有材料推演）

### 案例 1：Tier 1 —— 理想家庭（「小然家」）

**背景**：地级市双职工家庭；父亲出差多，主要由妈妈管学习；孩子七年级，数学 78 分，应用题失分最重；妈妈从小学辅导到现在。

**痛点**：妈妈讲题讲到发火，孩子从此不再问她；她打听过补习班，也买过教辅，孩子翻两页就放下。

**接触路径**：孩子的数学老师在一次家长会后提了一句「有个东西不是给答案的，可以试试」。

**首次体验的转折点**：孩子完整走完了一次 —— 拍照、听语音、点句子、自己打出「总人数不变」。**妈妈在旁边看完了全程，一句话没说。**

**妈妈的判断**（按 `07`·蓝海分析，她只需要看一件事）：「**它不是给他答案的，是让他自己想**。」

**付费**：当月付费，月付。**不是因为提分，是因为接下来两周孩子做作业没喊她。**

**对产品的价值**：完整的第一个真实案例；推荐原话的来源；「三秒澄清」与「15 分钟」两个指标的第一次实测。

---

### 案例 2：Tier 2 —— 边缘家庭（孩子成绩偏高）

**背景**：新一线城市；孩子数学 88 分，**审题问题不算明显**；妈妈工作忙，但愿意为工具付费。

**发生了什么**：孩子用了两次，觉得「太慢」——**他数学本来就还行，直接做比走流程快**。妈妈觉得产品「挺好的」，但三周后停止付费。

**教训**：**「成绩偏高」的孩子不是 ICP。** 他没有足够的痛点来承受「比直接做更慢」这个代价。
**而 `03` 已经指出，本产品的价值不在省时间**——这一点对这类家庭完全不成立。

**对 ICP 的修正信号**：**「家长辅导已失效」这一条的权重应当保持最高**——它比成绩区间更能预测留存。

---

### 案例 3：NOT ICP —— 一次弯路

**背景**：县城家庭；孩子数学 92 分；妈妈基本不参与学习，主要由奶奶照看；家里没有孩子的专属设备。

**发生了什么**：妈妈在群里看到推荐，给孩子注册了，用奶奶的手机试了一次，**奶奶不会操作，孩子试到一半就退出了**。之后再没打开过。

**浪费的资源**：创始人花了一个晚上远程陪同第一次体验——**而这是验证期最宝贵的资源**。

**教训**：
- **免费试用也需要筛选。** 「来者不拒」在验证期是资源的浪费
- 接触前用第七节的 5 个问题筛查，不合格的**礼貌拒绝**（「我们的产品目前比较适合家长能陪着看一眼的家庭，可能不太适合您家的情况」）
- **拒绝不是失礼**——为一个不适合的家庭省下时间，也是价值

## 十一、ICP 的扩展路径（二层 / 三层）

> **本产品的扩展维度不是「省份」，而是「学段」和「城市层级」**——因为 C 端没有区域政策差异（`04`·一）。

### 二层 ICP（学段扩展）

| 层 | 画像 | 扩展条件 | 为什么难 |
|---|---|---|---|
| **二层 A：八、九年级应用题** | 题型复杂度上升（分式方程、一元二次、函数应用题） | 七年级验证成功 + 有能力承接题型扩展 | **这是解决「生命周期只有一年」的唯一出路**（`03`·5.1），但难度显著上升 |
| **二层 B：小学高年级应用题** | 算术思维为主，「隐含条件」的形态不同 | 方法论需要出简化版 | 小学家长付费意愿与初中不同，需重新验证 |
| **二层 C：几何 / 函数题** | 条件画在图上，不在文字里 | **方法论需要重做** | **不是扩展，是重新发明一套方法**（`03`·8.1）——**优先级最低** |

### 三层 ICP（城市层级扩展）

| 层 | 画像 | 扩展条件 |
|---|---|---|
| 三层 A：一线城市 | 付费能力强，但选择多、要求高 | 二线 / 地级市验证成功且口碑成立之后 |
| 三层 B：县城 / 乡镇 | 基数最大，付费敏感，学习焦虑同样强烈 | **需要一个低价或免费增值的产品形态**——而那个形态现在还不存在 |

> **一句提醒**：`03`·5.1 已经算过——**用户生命周期最长一年**。
> 所以在所有扩展路径里，**二层 A（学段扩展）的战略价值远高于其他几条**：
> 它不只是「多一个市场」，而是**把这个产品从「一年生意」变成「三年生意」的唯一办法**。

## 十二、ICP 对 GTM 的指导

| GTM 决策 | ICP 给出的指导 | 具体执行 |
|---|---|---|
| **获客渠道** | **只有教师推荐不需要支付品类教育成本** | 不做投放（LTV/CAC = 1.9 已否决）；早期全部资源押在教师侧 |
| **核心信息** | 从**症状**开场，不从概念开场 | 不说「我们做审题训练」，说「**你家孩子是不是读完就动笔、老漏条件**」——让家长自己认领 |
| **定价锚点** | 家长的心理账户是「一次家教的钱」，不是「一个 App 会员」 | 锚「一节家教课的钱，够用一个月。而且它不会发火」；**月付、不做年付** |
| **转化动作** | **没有销售，只有第一次体验** | 首次完整体验免费、不限题数；**把资源全部投在「第一次 15 分钟」上** |
| **留存动作** | 家长的触点只有一个、30 秒、一周一次 | 每周一条记录；**必须带时间维度**；语言用她的话，不用产品的话 |
| **口碑机制** | 推荐语言里不会出现成绩（产品没有排名） | 推「**方法**」而不是「**结果**」：「原来应用题是这么读的」 |
| **不该做的事** | 反画像与负向 ICP 已明确 | **不投广告、不做排名、不做打卡、不承诺提分**——四条都是「不做」而不是「少做」 |
