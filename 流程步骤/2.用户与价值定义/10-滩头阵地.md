# 滩头阵地分析 — 数学审题逐题陪练系统

> 市场：中国 K12 AI 辅助学习工具（C 端 · 学生 / 家长付费）
> 学段：初中七年级 · 应用题
> 日期：2026 年 9 月

> **关联文档**：`08-理想客户画像`（谁是我们的人）、`04-竞品分析`（护城河与窗口期）、`03-市场规模估算`（单位经济与渠道可行性）、`02-SWOT分析`（P0—P2 与时间窗）
>
> **数据口径**：本文所有数字均为**估算或主观判断**，未经核实。产品尚未开发，**滩头尚未开始**。

> ### 与 B 端滩头的根本差别（读全文前先知道这一条）
>
> B 端的滩头是**地理 + 机构类型**：湖南省五市 × 省级示范性高中 × 高三化学组。
> 这样定义，是因为 B 端的销售靠**采购流程 + 关系网络**，而这两者都有地理属性。
>
> **本产品没有采购流程，也没有地理属性。** 它的转化靠一个动作——**一位教师说一句「你可以试试」**。
> 所以 C 端的滩头不是一片区域，而是：
>
> **一个人，加上他的关系半径。**
>
> 全文的每一个判断都建立在这条差别上。

## 一、候选滩头细分市场

| # | 细分市场 | 描述 |
|---|---|---|
| **A** | **1 位愿意推荐的七年级数学教师 + 他带的 2 个班** | 最小可验证单元——不需要任何审批、任何采购、任何地推 |

| **E** | **全国无差异投放** | **放弃**——违反滩头原则，且 `03`·6.1 已证明获客成本不可行 |

## 二、四标准评估

| 标准 | A（一位教师） | B（一所学校的年级组） | C（城市教研圈） | D（家长社群） |
|---|---|---|---|---|
| **1. 痛点强度** | 5/5 | 5/5 | 4/5 | 4/5 |
| **2. 付费意愿** | 4/5 | 4/5 | 3/5 | 3/5 |
| **3. 可赢性** | **5/5** | 4/5 | 3/5 | **2/5** |
| **4. 推荐潜力** | 4/5 | **5/5** | **5/5** | 4/5 |
| **综合** | **18/20** | 18/20 | 15/20 | 13/20 |

### 逐项说明

#### 1. 痛点强度

| 细分 A | 评估 |
|---|---|
| 教师每天直接看到「学生读不懂就动笔」——**这不是需要被说服的观点，是常识**（`04`·九） | 5/5 |
| 家长已经辅导到「一讲就吵」——痛点峰值在**每天晚上**，不是考试后 | |
| 学生卡住时无处可去：家长讲不清、老师问不到、搜题直接给答案 | |

**区别于细分 C**：教研圈里的教师**不在同一个班**，他们看不到彼此的日常，痛点强度相同但**紧迫感被稀释**。

#### 2. 付费意愿

| 细分 A | 评估 |
|---|---|
| 付费者是家长，决策周期是**数分钟到数天**（`08`·2.3） | 4/5 |
| 月度数十元（**估算**）——**低于「需要和配偶商量」的门槛** | |
| 但家长要先经历一次完整体验，**这一步的成功率决定了付费率** | |

**为什么不是 5/5**：产品尚未验证，且家长面对的是「为一套方法付钱」而不是「为一个成绩付钱」——**这是 ICP 层最根本的不确定性**。

#### 3. 可赢性（Winnable）

| 细分 A | 评估 |
|---|---|
| **不需要任何审批、采购、上架**——一位教师愿意说一句就够了 | **5/5** |
| 没有竞品在这一格：没有任何工具在做「审题训练」（`04`·三） | |
| 但同时——**也没有现成的需求认知可借用**（这是同一件事的另一面） | |

**区别于细分 D**：家长社群里是「来者不拒」的杂人群，**没有教师背书**，冷启动转化率极低（`03`·5.3：一个家长群约带来零点几个付费用户）。

#### 4. 推荐潜力

| 细分 B / C | 评估 |
|---|---|
| 教师的社交圈**高度同质化**——同一个教研组的、同一场教研会的 | 5/5 |
| 一场区县级教研活动可覆盖数十位教师，**是集中的推荐放大器** | |
| 家长之间的传播是**方法型**的（「原来应用题要这么读」），不冒犯、不攀比（`02-SWOT` 7.4③） | |

## 三、推荐滩头

### 滩头定义（越具体越好）

> **1 位愿意推荐的七年级数学教师 + 他带的 2 个班（约 90 名学生的家庭）。
> 同校再有 1—2 位教师形成互相印证。
> 然后向这位教师的教研圈（同城其他学校的七年级数学教师）扩散。**

### 为什么如此具体

- **「一位教师」而不是「一所学校」**——因为本产品**不需要机构决策**。定义到学校级别会把滩头做重
- **「2 个班」而不是「整个年级」**——第一次只需要一个班家长群的真实反馈
- **「同校 1—2 位教师」而不是「全组」**——孤证不可信，两条独立反馈才构成验证
- **「然后向教研圈扩散」而不是「先铺开」**——**滩头的目的不是收入，是验证「教师推荐 → 家庭试用 → 付费」这条链能不能跑通**

### 滩头规模测算

| 指标 | 值（**估算**） |
|---|---|
| 一位教师带班数 | 2 个班 |
| 每班学生数 | ~45 人 |
| **可触达家庭数** | **~90 个** |
| 其中有审题困难的比例 | 40% |
| 愿意试一次的比例（有教师背书） | ~50% |
| 试用家庭数 | ~18 个 |
| 试用到付费的转化 | ~30% |
| **一位教师带来的付费家庭** | **约 5—8 个/年** |
| **对应的年收入** | **约 600—960 元**（按实际年付费 120 元计） |

### 这个测算最重要的一句话

> **一位教师大约只能带来 5—8 个付费家庭、不到一千元的年收入。**
>
> 这与 B 端滩头（一所学校 = 3—5 万元/年）**差了两个数量级**。
>
> **所以 C 端滩头的作用不是「产出收入」，而是「验证机制」。**
> 它要回答的只有一个问题：**「教师说一句话 → 家庭完整试一次 → 家长付钱」这条链，到底通不通？**
> 一旦通了，剩下的全部工作是**把教师的数量放大**，而不是把单个教师做深。

## 四、候选滩头单元详细画像

> 替代 B 端文档中的「候选城市画像」——**C 端的单元是人，不是城市。**

### 4.0 单元评分模型

| 评分维度（权重） | 说明 |
|---|---|
| **教师本人的共鸣强度（30%）** | 他是否**不需要被说服**「审题值得单独练」 |
| **班级家长的组织度（25%）** | 有没有现成的家长群、群主是谁、平时聊不聊学习 |
| **学生家庭与 ICP 的匹配度（25%）** | 按 `08`·5.1 的 ICP 评分 |
| **教师的关系半径（10%）** | 他是否活跃于教研圈、是否乐于分享 |
| **可触达的时间窗（10%）** | 距离期中 / 期末还有多久 |

### 4.1 单元 A1 —「共鸣型教师」（首选）

| 维度 | 情况 | 评分 |
|---|---|---|
| 共鸣强度 | 他在教研组会上说过「现在的学生不是不会，是没读明白」 | **5/5** |
| 家长组织度 | 有班级群，班主任配合 | 4/5 |
| ICP 匹配 | 班级整体为主力 ICP 区间（数学中游） | 4/5 |
| 关系半径 | 参加区县教研活动 | 3/5 |
| 时间窗 | 开学后 2—6 周（课业压力已上来、离考试还远） | 4/5 |
| **加权总分** | | **4.2/5** |

**进入策略**：**不要演示亮点，邀请他挑毛病。** 他最在意的不是功能，是「判得准不准」——**让他自己找出一道判错的题，比给他看十个判对的功能更有说服力**（`06`·陈老师的洞察）。

### 4.2 单元 A2 —「犹豫型教师」（次选，但必试）

| 维度 | 情况 | 评分 |
|---|---|---|
| 共鸣强度 | 认同痛点，但**第一反应是「这是不是搜题的」** | 3/5 |
| 家长组织度 | 4/5 | |
| ICP 匹配 | 4/5 | |
| 关系半径 | 3/5 | |
| 时间窗 | 4/5 | |
| **加权总分** | | **3.5/5** |

**进入策略**：**先用一句话完成品类澄清**（「它不给答案」）——**如果这一句没说完，后面所有的话都听不进去**。
**并且这一类教师的价值高于 A1**：**能说服一个怀疑者，才说明定位表达是有效的。** A1 的认可可能是礼貌性的。

### 4.3 单元 B1 —「同校第二位教师」（验证环节）

**作用**：**验证 A1 的反馈是真话还是客气话。**
如果第二位教师在**没有直接推荐**的情况下（只听说同事在用）也认可，**A1 的反馈可信**；如果第二位无感，**A1 可能是礼貌性好评**。

**执行方式**：**不主动联系第二位教师**，只观察他会不会自己来问。**「自来」是这里唯一有效的信号。**

### 4.4 单元 C1 —「区县教研活动」（扩散放大器）

| 维度 | 情况 |
|---|---|
| 一场区县级七年级数学教研活动 | 参与的教师数：**估算** 20—60 人 |
| 覆盖学校数 | 10—30 所 |
| 推荐方式 | **不是我们讲，是 A1 那位教师讲**——「我班上试过」 |
| 关键指标 | 活动后主动来问的教师人数 |

**这里的核心判断**：**教师愿意在教研活动上主动提起，才算推荐机制成立。**
如果他只是在我们请求下才说一句，那不是推荐，是人情。

## 五、12 周滩头执行计划

> **与 B 端的差别**：没有「入职培训」「全组激活」「合同签署」这些环节。
> C 端的执行动作只有三类：**让一个学生走通一次 → 让一位家长看懂一次 → 让一位教师愿意说一句。**

### 整体节奏

```
Week 1-4：   让第一个学生完整走通一次（验证产品最小的成立条件）
Week 5-8：   让第一批家长看懂并付费（验证转化链）
Week 9-12：  让第一位教师自发说一句（验证推荐机制）
```

### Week 1—4：让第一个学生完整走通一次

| 周 | 关键活动 | 成功指标 | 风险缓解 |
|---|---|---|---|
| 第 1 周 | 找到 1 位教师，请他看一遍产品；**明确说明「先别推给学生，你先自己挑毛病」** | 教师试用 1—2 道题后，能说出「它不给答案」 | 如果他被第一印象吓退 → **说明首屏的品类澄清失败了**，这是要修的第一件事 |
| 第 2 周 | 找 1—2 个真实学生（最好就是这位教师班上的）走第一次 | **完整走完一次；记录每一步停留的秒数** | 中途退出 → 记录**退在第几步、屏幕停在哪**——这是最有价值的反馈 |
| 第 3 周 | 修复第一次暴露的最大摩擦点（**优先看时长**） | 首体验（S1–S8）**≤ 15 分钟** | 若压不到 15 分钟 → **砍环节，不是优化措辞**；完整闭环只记录 |
| 第 4 周 | 让 3—5 个学生各自独立走一次 | 首次完成率 ≥ 70%；**无人在前 3 分钟退出** | 完成率低 → 逐项排查时长 / 打字摩擦 / 语气 |

**产出**：
- 1 份「首体验实测记录」（含每一步的实际耗时）
- 1 份「摩擦点清单」（按严重程度排序）
- **一个能回答「首体验 15 分钟能不能做到」的数字**——这是本阶段唯一真正重要的产出

### Week 5—8：让第一批家长看懂并付费

| 周 | 关键活动 | 成功指标 |
|---|---|---|
| 第 5 周 | 请教师在一个班级群里**用一句话**提一次产品 | 教师愿意发；且这句话是他自己组织的（不是我们给的文案） |
| 第 6 周 | 观察家长的反应——**重点不是转化，是她的第一句话问的是什么** | 出现「**这不是搜题的吧**」或「**不给答案那有什么用**」→ 这两句都是有效反馈 |
| 第 7—8 周 | 首批付费尝试：**首次体验完全免费，之后月付** | ≥ 5 个家庭完成完整首次体验；≥ 2 个家庭付费 |

**产出**：
- 1 份「家长的第一反应」记录（原话）
- 1 份转化漏斗：触达 → 试用 → 付费
- **一份家长能复述「它不给答案」的比例**

### Week 9—12：让第一位教师自发说一句

| 周 | 关键活动 | 成功指标 |
|---|---|---|
| 第 9 周 | 不做任何推动，**观察教师会不会自己再提** | 他有没有在不被提醒的情况下再说一次 |
| 第 10 周 | 请第二位教师（同校）看一次——**但不做推介，只让他知道有一位同事在用** | 他会不会自己来问 |
| 第 11 周 | 如果前两周成立，请第一位教师在一次教研活动上提一句 | 活动后主动来问的教师人数 |
| 第 12 周 | 12 周复盘——**评估滩头定义本身是否需要改** | 至少 1 位教师自发推荐；至少 2 个家庭付费 |

**产出**：
- 12 周滩头总结报告
- 「教师推荐 → 家庭试用 → 付费」漏斗的完整数据
- **Go / No-Go 建议**

## 六、滩头资源需求与预算

### 6.1 人力需求

| 角色 | 投入度 | 90 天工作量 | 关键活动 |
|---|---|---|---|
| **产品负责人**（当前唯一执行者） | 兼职即可（**这与 B 端差别极大**） | **约 30—40 人天** | 产品迭代、教师沟通、学生观察、家长访谈 |
| 外部支持 | 无 | — | **没有内容顾问、没有销售、没有驻校** |

> **C 端滩头的人力投入远低于 B 端**（B 端 90 天需 100+ 人天）。原因是**没有 onboarding、没有培训、没有合同**——
> 唯一的工作是**观察、修复、再观察**。

### 6.2 财务预算

| 项目 | 金额（元） | 说明 |
|---|---|---|
| 模型 API（3 个月） | 100—300 | 单次陪练成本在角分量级，用户量极小 |
| 域名 / 静态托管 | 100—300 | 第一版是一张 HTML，托管成本可近于零 |
| 语音（TTS） | **0** | 浏览器自带 Web Speech API |
| 教师酬谢 | 600—1,500 | 深度访谈的小礼物，每人 200—300 元 × ≤ 5 人 |
| 差旅 | 0—1,000 | **优先线上**——C 端不需要驻校 |
| 应急储备 | 1,000—2,000 | |
| **合计（90 天）** | **约 1,800—5,100** | 中位数约 **3,000 元** |

**关键发现**：**滩头 90 天的中位预算约 3,000 元**——比一个 B 端工具（约 11,000 元）更低，
**这是 C 端唯一一处结构性优势：验证成本极低。**

**它带来一个重要的战略含义**：**「验证不起」不构成不验证的理由。**
如果连 3,000 元和 90 天都不愿意投入，那不是资源问题。

## 七、滩头成功指标与退出条件

### 7.1 阶段性指标

| 时间节点 | 完整走过的学生数 | 付费家庭 | 首次完成率 | 首体验时长（S1–S8） | 能复述「不给答案」的家长 | 自发推荐的教师 |
|---|---|---|---|---|---|---|
| **第 3 个月末** | 5—10 | 2—3 | ≥ 70% | ≤ 15 分钟 | ≥ 60% | 1 |
| **第 6 个月末** | 30—50 | 15—25 | ≥ 70% | ≤ 15 分钟 | ≥ 70% | 3 |
| **第 12 个月末** | 200—500 | 100—300 | ≥ 75% | ≤ 15 分钟 | ≥ 80% | 10 |

> **注意第 12 个月末的付费家庭数（100—300）**——它对应 `03`·2.2 的基准到乐观区间。
> **这个数字远小于一个 B 端滩头（10 所学校 = 数百万元），但它是 C 端真实的量级。**

### 7.2 滩头成功的量化定义

| 指标 | 退出阈值（必须达到） | 理想阈值 | 测量方式 |
|---|---|---|---|
| **判定可靠性（误判正例率）** | **= 0** | = 0 | 开发前实测（`02-SWOT` P0） |
| **首体验完成率（S1–S8）** | ≥ 70% | ≥ 80% | 产品埋点 |
| **首体验时长（S1–S8）** | ≤ 15 分钟 | ≤ 12 分钟 | 产品计时；完整闭环另记 |
| **家长能复述「它不给答案」** | ≥ 60% | ≥ 80% | 体验后复述 |
| **次月续费率** | ≥ 60%（**估算**） | ≥ 80% | 付费数据 |
| **教师自发推荐人数** | ≥ 3 | ≥ 5 | 记录（**必须是"自来"**） |
| 非熟人带来的新用户占比 | ≥ 20% | ≥ 40% | 来源归因 |

**第一行是一条红线，不是一个目标。** 误判正例率不为零，产品的其余指标全部无效——
因为学生会照着一个错误的标准改自己（`02-SWOT` ST-2）。

### 7.3 定性成功指标

| 指标 | 阈值 | 验证方式 |
|---|---|---|
| **教师在无人请求下主动提起** | ≥ 1 次 | 记录（这是推荐机制唯一有效的证据） |
| 家长的原话里出现「不用再讲」 | ≥ 3 位 | 访谈原话 |
| **学生自己想起来用**（不是家长催） | ≥ 1 例 | 家长观察 |
| 有人主动问「这是哪个」 | 出现 | 记录 |

### 7.4 退出条件（全部满足）

1. **判定可靠性达标（误判正例率 = 0）**
2. 首次完成率 ≥ 70%，且首体验（S1–S8）≤ 15 分钟；完整闭环只记录
3. 家长能复述「它不给答案」的比例 ≥ 60%
4. **至少 3 位教师在无人请求的情况下主动推荐**
5. 至少 2 个家庭完成次月续费
6. **没有出现「被误认为搜题工具」的负面事件**

**预计滩头时间：6—12 个月**——比 B 端（12—18 个月）短，因为**单位小、验证快、没有采购流程**。

### 7.5 Go / No-Go 中期检查点

| 时间点 | 检查什么 | Go 条件 | No-Go 条件 |
|---|---|---|---|
| **第 30 天** | 第一个学生能不能走完 | ≥ 1 人完整走完 | **有人在前 3 分钟内退出** |
| **第 90 天** | 家长能不能复述产品是什么 | ≥ 60% 说出「不给答案」 | < 30% |
| **第 180 天** | 有没有人付费并续费 | ≥ 2 个家庭完成次月续费 | 0 个 |
| **第 365 天** | 有没有人自发推荐 | ≥ 3 位教师 | 0 位 |

### 7.6 失败信号与应对

| 失败信号 | 说明它意味着什么 | 应对 |
|---|---|---|
| **首个学生 3 分钟内退出** | 首屏的品类澄清失败了 | **改首屏，不是改流程**（`02-SWOT` ST-1） |
| 走完了，但家长说不出产品是什么 | **定位表达失败，不是产品失败** | 改文案（`09`·六），不要改产品 |
| 家长体验完不付费 | 价值被承认，但价格锚点错了 | 检查锚点是不是锚到了「通用 AI = 0 元」 |
| **付费了但不续费** | 家长端的桥没搭好 | 重做那 30 秒的记录呈现（`06`·二） |
| 教师认可但不愿推荐 | **推荐对教师有成本**（怕担责、怕家长追问） | 把推荐从「口头」改成「可转发的内容」，把成本降到接近零 |
| 学生第二次不打开 | 时长或打字摩擦 | 回到 Week 1—4 的实测记录逐项排查 |

## 八、滩头竞争评估

> **C 端的竞争不按城市分布，按替代方案分布。** 每一个家庭面前同时站着全部替代方案。

| 替代方案 | 在滩头家庭中的存在度 | 本产品的位置 | 应对 |
|---|---|---|---|
| **家长自己辅导** | **极高**——份额 > 80%（`04`·二） | **不是替代，是补位** | 「不替代你，只做你做不到的那一段」 |
| **通用 AI 助手** | 高——**已经在手机里，且免费** | **方向相反**：它给答案，我们不给 | 不拼方便，拼它做不到的（有记忆、语气可控、不给答案） |
| **拍照搜题类** | 高——学生对「拍题」的动作已形成习惯 | **形态相似、方向相反** | 必须主动澄清——**形态上不存在答案入口** |
| **学习机 / 题库类** | 中 | 它们在讲题和刷题，不在训练读题 | 「审题训练不替代刷题，它解决刷题替代不了的那个问题」 |
| **免费讲题内容** | 中 | 互补——内容建立认知，产品完成训练 | 主动承认互补关系，减少对抗 |

**本产品在滩头的竞争位：一个「方向相反」的东西，站在五个替代方案的缝隙里。**

> **与 B 端最不同的一点**：B 端可以说「讯飞做阅卷，我们做诊断——互补」。
> **C 端没法这么说**，因为**通用 AI 助手不是互补，是同一件事的相反做法**。
> 这是滩头竞争中最需要解释、也最难解释的一格。

## 九、滩头退出后的相邻扩张序列

```
滩头（6—12 个月）
1 位教师 + 2 个班
        │
        ├── 路径 1：同校其他七年级教师（第 3—6 个月）
        │    零边际成本；验证"不看推介也会来"（4.3 节的 B1 单元）
        │
        ├── 路径 2：该教师的教研圈（第 6—12 个月）
        │    一场区县教研活动 ≈ 20—60 位教师、10—30 所学校
        │    这是 C 端唯一的"批量触达"机会
        │
        ├── 路径 3：★ 学段扩展 → 八、九年级（第 12 个月起）
        │    ★ 这条的战略价值远高于其他几条
        │    它把"一年生意"变成"三年生意"（03·5.1）——解决生命周期这个结构缺陷
        │    代价：题型要扩（分式方程、一元二次、函数应用题），方法论要改
        │
        ├── 路径 4：城市层级扩展（一线 / 县城）
        │    一线：要求更高、选择更多
        │    县城：需要一个低价或免费增值的形态——而那个形态现在还不存在
        │
        ├── 路径 5：内容渠道（教育类内容账号）——规模化触达
        │    前提：已有可复述的成功故事与家长原话
        │
        └── 路径 6：跨题型（几何 / 函数）——优先级最低
             条件写在图上而不是文字里，四类句子这套切法失效
             **不是扩展，是重新发明一套方法**（03·8.1）
```

### 扩张节奏的四条原则

1. **先纵深后横向**——把「一位教师 → 他的班 → 同校同事」这一小段做到自发，再谈教研圈
2. **先自发后推动**——**只有"看出来的"推荐才算数，"请出来的"不算**。这是本产品唯一的渠道机制，不能掺水
3. **先验证后规模**——路径 1、2 的意义不是收入，是确认机制可复制
4. **学段扩展单独立项**——路径 3 不是"扩张"，是**解决产品结构性缺陷**，应当作为独立项目评估，而不是顺带做

## 十、滩头案例积累计划

| 案例类型 | 数量目标 | 用途 | 优先级 |
|---|---|---|---|
| **家长的原话** | 3—5 条 | **所有对外文案的素材** | **最高** |
| 一次完整陪练的实测记录 | 1 份 | 内部：验证时长与摩擦点 | 高 |
| 教师的推荐语（他自己组织的） | 2—3 条 | 教师侧传播 | 高 |
| **「被误认为搜题工具」的实例** | 越多越好 | **用于修正首屏**——负面反馈比正面反馈有用 | 高 |
| 学生自己想起来用的记录 | 1—2 例 | 验证学生侧的粘性 | 中 |

### 案例采集标准

**家长原话 > 数据。**

原因很直接：**本产品的可信度建立在「具体的感受」上，而不是「提升的百分比」上**——
因为它不承诺提分（`05`·第三节），也就没有数据可炫。**它唯一能说的是：**

> 「讲了八百遍还是错，最后两个人都生气。」
> 「现在他自己用这个读题——**它不给他答案，就是一句一句问他**。」

**这两句话比任何指标都有说服力。**
